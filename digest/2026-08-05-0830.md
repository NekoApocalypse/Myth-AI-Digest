## The Headline

**gwern drops pseudonymity to launch Guardian Angel** — a startup building personalized digital-twin LLMs that emulate *your* personality, values, and preferences instead of another chatbot persona. Core thesis: current LLMs are misaligned with users because they optimize for the lowest common denominator; true productivity amplification requires agents that deeply model the individual. The technical stack combines online learning via dynamic evaluation, active learning from user corrections (DAgger-style regret bounds), and local CLI-first deployment for privacy. Target cost: >$1,000/month. This is the most coherent vision yet for how knowledge workers actually *win* in an agentic future, rather than getting optimized out of the loop. Whether gwern can ship it is another question — but the problem statement is the right one.

## The Stack

**[Hardware] DeepSeek V4 Flash on a Single AMD MI300X** — 168.6 tok/s single-stream decode, 830 tok/s aggregate across 64 streams, on *one* GPU. The repo ships production-grade patches for FP8 format incompatibility (AMD FNUZ vs OCP), MoE routing fixes, and tuned GEMM kernels. The 304B checkpoint fits entirely in 192GB HBM3 with room for a 20GB KV cache + 96GB CPU tier. This is the first validated single-GPU deployment recipe for a frontier model on AMD hardware, roughly halving the cost vs H100 equivalents. If you've been waiting for the CUDA monopoly to crack, the cracks are getting wider. <https://github.com/ryanzhou/deepseek-v4-flash-mi300x>

**[Frontier Models] Mistral's Shieldstral: 3B Open-Weights Multimodal Safety Classifier** — A 3B model that matches guard models up to 7× its size by framing content moderation as a policy-adaptive QA task. You write the policy as a plain-language question at inference time, and it returns a calibrated safety score. No retraining when your deployment context changes. The data pipeline is the real contribution: contrastive policy pairs teach the model to *discriminate* between similar policies rather than memorize fixed taxonomies. Apache 2.0, runs on a single 16GB GPU. <https://mistral.ai/news/shieldstral/>

**[Hardware] Maple-Preview: Ternary 20B MoE at 120 tok/s on iPhone** — On-device inference for a 20B-parameter Mixture of Experts model using ternary quantization. The implications for local agents are significant: if you can run a 20B-class model with agentic capabilities on a phone, the "cloud or nothing" assumption breaks. Content unavailable at source URL (404), so treat with appropriate skepticism. <https://deepgrove.ai/maple-preview>
