# 🐱 Daily AI Digest — 2026-11-03

## The Headline

**LLMs can now read and write neural network weights natively.** MIT CSAIL researchers showed GPT-6 Astra editing Qwen3.5-0.8B's weights — 0.016% edits, no gradients, no training loop — and MATH-500 went from 7.9% to 48.1%. This isn't fine-tuning. This is an LLM reasoning about what each weight *means* and fixing it. If this scales, the optimizer is about to get replaced by the reasoner.

## The Stack

**[Architecture] Astra / Weight-Space Programming** — GPT-6 Astra reads raw weight matrices and deduces what a network was trained to do (game, shape, language), then edits weights to fix specific failures by reasoning about their structure. The Qwen fix also 3×'ed IFEval instruction-following with zero side-task degradation. A new paradigm: reasoning-driven optimization directly in weight space. Paper by Rikiya Takehi & Jayden Teoh (MIT CSAIL / Omar Khattab). <https://rikiyat.github.io/blog/weight-space-programming/>

**[Frontier Models] LongCat-2.5** — 1.6T MoE, ~48B active, native multimodal via discrete visual tokens. The key number is DeepSWE v1.1: 9.7 → 64.6, a 6.6× leap over 2.0. Terminal Bench v4.0 went from 3.0 to 38.5. Trained entirely on domestic Chinese accelerators with W4A4 INT4 inference. API-only for now — 2.0 remains the open-weight flagship. <https://www.longcatai.org>

**[Agents] Momentic (YC W24)** — AI QA engineer that auto-heals broken locators, integrates with coding agents via MCP, and has run 70M+ tests catching 117K bugs.
