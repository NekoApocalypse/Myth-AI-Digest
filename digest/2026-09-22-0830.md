# Daily AI Digest — 2026-09-22

**The Headline: Tim Dettmers ships a local AI ecosystem that runs 125B models on consumer GPUs and autonomous research agents that beat Google ScientistOne — all open source.**

His lab at UW published an entire open-source week: an inference framework that runs Qwen 3.8 Flash Next (125B) on a single 24GB GPU, DeepSeek V4.1 (550B) on a MacBook with 128GB RAM, and quantized Qwen 35B at 450 tok/s on Apple Silicon at 1.5 bits per weight. The autonomous research agent outperforms both Sakana AI's system and Google's ScientistOne on literature-driven research tasks, running entirely locally with no internet access. The CliffCompaction auto-compaction technique cuts agent session costs by ~50% with sessions exceeding 100M tokens, and already one partner reported a 45% reduction in their total AI budget after deploying it. This isn't a blog post flex — his students use it daily and asked him to turn it back on when he stopped.

<https://timdettmers.com/2026/09/21/dlab-open-source-week/>

## The Stack

**[Frontier Models] Grok 4.7** — xAI ships its most capable coding model at the same $2/$6 pricing as 4.6. CursorBench 4.0 hits 46.3% (vs GPT-5.6 Sol Max at 41.7%), Terminal-Bench jumps from 20.3% to 38.0%, and DeepSWE v1.1 reaches 71.0%. The real story is the new safeguard stack: 3.3% dual-use prompt pass-through on HackerBench, best biosafety score on LatchBio at 62.4%. They're also giving select security partners invite-only red-team access. Same price, larger base model, longer RL on harder multi-hour tasks. Available in Cursor and Grok Build today.

<https://x.ai/news/grok-4-7>

**[Agents] Kev — Jared Palmer open-sources a family of decision models (0.8B, 4B, 9B) built on Qwen3.5**, drop-in compatible with TypeSafe's System One API. Kev-9B scores 0.852 on out-of-distribution sources (Jev hosted: 0.857). Runs locally on CUDA, ROCm, and Apple Silicon with calibrated probabilities. Ships with a web playground, chess demo, and training code. This is an open-source clone of a closed-source decision-routing API — the kind of infrastructure that lets you build agentic pipelines without vendor lock-in.

<https://github.com/jaredpalmer/kev>

**[Agents] Linear's CI couldn't keep up with AI-generated PR volume, so they rearchitected it.** Test suites 4x since January, but PR wait time dropped from >6 min to ~5 min and runner time per test halved. Key wins: tsgo cut tsc by 73%, dumping type-aware lint rules for AST-only static analysis, scoped pnpm install (73s → 18s), vitest file-level sharding with module reuse, and batching 7 short checks into 2 jobs (saving 87k runner-minutes/month). A rare engineering post that actually tells you how much each optimization saved, not just that they "made things faster."

<https://linear.app/now/ci-bottleneck-reworked>

**[Frontier Models] Xiaomi MiMo v2.6** — 468 points with 237 comments. A new multimodal model release from Xiaomi. The content page is JS-rendered and inaccessible via basic fetch, but the community traction suggests this is a significant release in the Chinese frontier model landscape. Worth tracking.

<https://mimo.xiaomi.com/mimo-v2-6>
