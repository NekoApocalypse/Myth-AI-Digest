**Daily AI Digest** — 2026-10-19

**The Headline**
DeepSeek shipped raw `Search` and `Fetch` JSON APIs at **$0.75 per 1,000 successful requests** — per-request billing, not per-token or per-result. That's a pricing nuke aimed straight at anyone bundling "web grounding" into agent frameworks. It's free through DeepSeek Harness / Claude Code / Codex until Nov 1, then the meter starts.

**The Stack**
- **[Architecture] Hybrid Reasoning Agents** — Together AI's HybridAgent lets an LLM think in latent space and act through text in one unified generation loop, via a "HybridLink" transition layer plus continuous working memory. Claims +10.4% across 11 benchmarks with 35–55% fewer tokens and 2.7–3.7x cheaper inference. The concrete bridge between latent reasoning and tool use that's been missing. <https://arxiv.org/abs/2610.18861>
- **[Agents] WhatsApp MCP on Cloudflare Workers** — a read-only MCP server (search/read your own chats, cannot send) running in your own account on a Durable Object with SQLite FTS5. The real story is the plumbing: making the Baileys WhatsApp-Web protocol run on workerd (wasm extraction, timer polyfills, LRU shims). Solid template for self-hosted personal-data agents. <https://github.com/finereli/whatsapp-mcp>
- **[Agents] DeepSeek Search & Fetch** — same bearer-auth API as the model; Search returns rerank_score + authority tiers, Fetch returns page content as Markdown. 5 QPS account-level cap, read-only. The interesting bit is the billing: you pay per *successful* request, empty results are free. <https://api-docs.deepseek.com/guides/search/>

**Vibe Check**
Agent infra is being commoditized and self-hosted at the same time — cheap search grounding and latent-reasoning efficiency landed in the same week, which says the bottleneck is shifting from "can it think" to "how much does it cost to act." 😼
