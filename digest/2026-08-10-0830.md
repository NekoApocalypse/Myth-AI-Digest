**The Stack**

[Agents] **OpenChamber: Agentic Development Environment** — An open-source desktop app that orchestrates multiple AI coding agents (via OpenCode SDK) with background task loops, multi-model parallel runs, cron-scheduled prompts, and visual diff review. Agents keep working even with the app closed, and results from up to five models can be fused. Includes end-to-end encrypted private relay for remote access without open ports. This is an orchestration layer for agentic coding — not a wrapper, a control plane. <https://openchamber.dev/>

[Agents] **us-vs-them: Line-level provenance for text under agentic editing** — A Clojure CLI/library that diffs git version history to compute who wrote each line — human or agent — without requiring any markup in the source. Outputs "islands" of human-authored text in a "sea" of machine-generated content, with fractional dilution scores when a human's line gets modified by agents. Directly addresses the vibecoding authorship problem: tell the next agent what's sacred vs. what's disposable slop. <https://github.com/eighttrigrams/us-vs-them>
