## The Stack

**[Frontier Models] Kolibri — Sovereign Open-Weight 78B MoE** (490 pts)
Aleph Alpha released Kolibri on German Reunification Day. 78.1B total parameters, 3.46B active via 384 experts (6 active per token), sliding-window attention across 40 of 50 layers with full attention every 5th layer. Custom UniBPE tokenizer beats GPT-5's by 11.2% on German text. Explicit reasoning effort levels (none/low/medium/high), tool calling, and trained abstention via their Merlin-Arthur procedure — the model refuses to answer when evidence is absent, avoiding wrong answers on 44% of tricky cases vs 14.8% for the predecessor. Two A100 80GB minimum. Weights on Hugging Face. <https://aleph-alpha.com/>

**[Agents] Opus 5.5 Playbook — Official Anthropic Guide** (150 pts)
Addy Osmani's official guide for getting real work out of Opus 5.5 in Claude and Claude Code. The headline shift: Opus 5.5 runs autonomously for hours, so the playbook is about steering not prompting. Key moves — name the finish line in one message, delete all "think carefully" lines (it thinks before every reply), write CLAUDE.md rules for stop-vs-continue decisions, fan audits out to subagents, and keep task lists in files so they survive context summarization. One early tester: Opus 5.5 at lowest effort caught more bugs than Opus 5 at high effort, with fewer false alarms. <https://claude.dev/blog/getting-the-most-out-of-opus-5-5/>

**[Agents] Pi Pod — Self-Hosted Agent Sandboxing** (73 pts)
Open-source platform that wraps the "pi" coding agent harness with sandboxed execution, RBAC session sharing, and browser/native-app automation. Aimed at teams who want their agentic infrastructure on-prem rather than in someone else's cloud. Still early but the philosophy is right: boring infrastructure for agent engineering. GitHub repo available, hosted tier coming. <https://pipod.dev/>

**[Agents] Agents Don't Need Memory, They Need Documentation** (33 pts)
Title says the argument: agent persistence should come from structured documentation rather than accumulated context/memory. Content unavailable (site blocked), but the framing is sharp enough to note — "documentation as agent memory" is a design pattern worth testing against the prevailing "just stuff everything in context" approach.
