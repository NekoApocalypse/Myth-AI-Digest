# 🐱 Daily AI Digest — 2026-10-13

## The Headline
**Meta ships Muse Wonder**, a frontier model series purpose-built for persistent agentic workflows — not just another benchmark beater, but a model architected around memory and sustained task execution. This is Meta's most credible push toward "personal superintelligence" yet.

## The Stack

[Frontier Models] **Muse Wonder & Muse Wonder Full** — Meta's new agent-first frontier models with Active Memory (cross-conversation context) and Active Focus (sustained task execution with self-correction). Available via Meta Model API and Muse Code. SOTA on Harvey LAB legal benchmark and FocusBench. Trained at Meta's gigawatt-scale Prometheus DC. <https://research.meta.ai/blog/muse-wonder> *(507 pts, 275 comments)*

[Frontier Models] **Z.ai GLM-Legal** — A legal-domain agent model built on GLM-5.3-Flash (320B MoE, 18B active), trained via RL across tens of thousands of legal environments. 19.2% all-pass on Harvey LAB — a 12.5pp jump over the base model. Gated beta; runs on Z.ai's AutoClaw desktop agent. <https://z.ai/blog/glm-legal> *(408 pts, 235 comments)*

[Agents] **Codex CLI 0.157.0 silently installs a background daemon** — Installing or running `codex` now spawns a persistent, self-updating daemon that copies ~374MB of binaries, runs detached from the TTY, checks for updates every hour, and auto-restarts — all without asking. The GitHub issue has blown up because it also pins proxy env vars from the first session and the updater can kill active turns. Workaround: `codex features disable daemon_auto_start`. <https://github.com/openai/codex/issues/48195> *(431 pts, 227 comments)*

[Agents] **Agent37 (YC F26)** — Low-cost agent sandboxes at ~$0.37/month average. gVisor isolation on bare-metal Hetzner/OVH, per-minute billing, pre-loaded with Hermes/OpenClaw/Claude Code/Codex harnesses. One customer dropped from $85/month to $4.94/month per agent. The playbook: skip hyperscaler VMs, share memory across sandboxes, bill for usage not uptime. <https://agent37.com> *(89 pts, 61 comments)*

[Hardware] **Janas — run 80B models on 32GB laptops** — Pure C, zero-dependency MoE inference engine that streams experts from NVMe SSD. Qwen3-Next-80B (48GB model) does 37 tok/s generation on a 32GB laptop where llama.cpp manages 2.8 tok/s. Reading: 62 vs 16 tok/s. Faster than llama.cpp on all 13 models benchmarked in Q4_K_M. Deliberately hard on the machine — fills free RAM with expert cache, reads disk at full speed with O_DIRECT. <https://github.com/prabanta-dev/janas> *(12 pts — underrated)*

[Hardware] **Intel GPU D270 (Crescent Island)** — Intel's first merchant-silicon inference GPU. 32 Xe3P cores, 256 XMX engines, up to 480GB LPDDR5X, 1.3 PFLOPS FP8 at 350W air-cooled PCIe 5.0. Single card handles models up to 300B params; 8-card system targets 1T+. LPDDR5X instead of HBM — lower bandwidth (1.5 TB/s) but avoids the HBM supply crunch. Customer sampling started, no ship date. <https://www.intel.com/content/www/us/en/products/details/discrete-gpus/data-center-gpu/d-series.html> *(25 pts)*
