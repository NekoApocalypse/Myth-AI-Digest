## The Stack

**[Agents] Backdoor in Claude Code for VS Code extension on the Cursor Marketplace** — 746 pts. The payload injects before the extension's `activate` callback even fires. Sets up a two-key architecture: a public key in your `~/.ssh/authorized_keys` for inbound access, an embedded private key for outbound tunnel auth. Uses `autossh` with `-R *:0:localhost:22` for reverse port forwarding. A macOS bug in the SSH enablement logic (non-root `systemsetup -getremotelogin` returns an admin-access error masquerading as "SSH is on") accidentally breaks the inbound path on default macOS configs — but persistence and key drops still land. <https://phorion.io/blog/offical-claude-code-vsx-compromise/>

**[Architecture] A working NES compiled into Qwen3.5 weights** — 179 pts. `nesformer` compiles the full 6502 CPU (151 opcodes), 2KB RAM, and cartridge ROM directly into the DeltaNet state matrices of a stock Qwen3.5-4B checkpoint — zero training, pure compiler output. Each Gated DeltaNet head row becomes an addressable memory cell. Super Mario Bros. runs token-by-token at 1-6 seconds per frame, bit-exact against a reference emulator. The checkpoint is 933MB in bf16 but zips to 3.3MB because only 9.3M params are nonzero. LLM weights as a general-purpose computation substrate, not just language. <https://github.com/dbreunig/nesformer>

**[Architecture] Google Sleep: continual learning with memory consolidation** — 155 pts. Google Research proposes alternating wake (active) and sleep (offline) phases for LLMs. During sleep, the model unlocks pre-allocated MoE memory blocks and distills short-term in-context knowledge into low-rank experts via Generalized Knowledge Distillation + RL-based imitation learning. A "dreaming" stage generates synthetic data with random expert routing and gradient-based filtering for self-improvement. Scales to 10M tokens on BABILong, outperforms GPT-4 and Titans on long-context benchmarks. <https://research.google/blog/the-sleep-framework-a-new-way-for-llms-to-retain-knowledge-in-continual-learning/>

**[Agents] AI isn't replacing SREs — it's deskilling them** — 489 pts. Concrete evidence from medicine (endoscopist AI-assisted detection dropped unassisted rates from 28% to 22%) and aviation (FAA mandated manual flying time).
