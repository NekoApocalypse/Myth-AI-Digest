# Daily AI Digest — 2026-08-20

## The Headline

**Ornith-1.5 drops with a closed-loop self-improvement training recipe and matches Claude Opus 4.8 on Terminal-Bench.** The flagship 397B MoE hits 86.1 on Terminal-Bench 2.1 and 56 on DeepSWE — numbers that put it neck-and-neck with Anthropic's best while being fully open-weight. What makes this different from the usual benchmark-chasing release is that the model *generated its own curriculum*: it proposes harder tasks, builds its own evaluation scaffolds, and uses rollout rewards to drive GRPO across all three stages. The 9B dense version runs on phones and still beats Gemma 4-31B. Recursive self-improvement at production scale, not a preprint.

## The Stack

**[Frontier Models] Ornith-1.5: From Self-Scaffolding to Self-Improvement** — Three-model family (397B MoE / 35B MoE / 9B dense) trained via end-to-end self-improvement where the model generates tasks, scaffolds, and solution rollouts for RL. The task reward function is multiplicative: validity × frontier difficulty × novelty. As the model gets better, old tasks become less rewarding, so the curriculum auto-advances. The 9B version on mobile hardware outperforms Gemma 4-31B on coding benchmarks. <https://ornith.ai/ornith_1_5.html>

**[Hardware] Unsloth Dynamic 3.0 GGUFs** — Major upgrade to Unsloth's post-training quantization. New calibration dataset optimized for agentic coding + multilingual chat, smarter per-layer quantization selection. Pure PTQ, no QAT/QAD training tricks. The IQ1_S quant at 6.2GB retains ~72% top-1 accuracy while being 89% smaller than BF16 — that's a capable local agent fitting on consumer GPUs. Compatible with llama.cpp and Unsloth Desktop. <https://unsloth.ai/docs/basics/dynamic-3.0-ggufs>

**[Agents] fx — Tiny, open, native coding agent** — A 6MB Zig binary that cold-starts in 10µs. Model-agnostic, shell-like UI, single-digit MB memory baseline. WASM target support means it can run inside browser sandboxes and edge environments where Python agents can't go. Think "coding agent as a Unix utility" rather than "IDE in your terminal." Apache 2.0. <https://fx.sh>

**[Agents] Collaborative Human Agent Protocol (CHAP)** — A JSON-RPC 2.0 protocol for recording human-agent collaboration as a content-hashed audit chain. When you override an agent's output, CHAP captures the diff, rationale, and tags — making "which prompts need work?" a query instead of a post-mortem investigation. Ships with MCP and A2A transports, plus framework bridges for LangGraph, Pydantic AI, AutoGen, LlamaIndex, and Google ADK. Turns supervision into structured data as a side effect. <https://github.com/BrightbeamAI/chap>

**[Breakout] Mathematics in the Age of AI** — Terence Tao's ICM 2026 lecture essay. Rather than debating whether AI will achieve research-level math, Tao conditions on *yes* and asks: what are the goals and values of mathematical research? He proposes a rule of thumb — if no human can give a clear expert-level talk on a result, it shouldn't be published, even if formally verified by Lean. The HN thread (107 comments) is a genuine philosophical brawl between formal-verification maximalists and those arguing math is an inherently human epistemological practice. <https://arxiv.org/abs/2608.16753>

## Vibe Check

Self-improvement training is eating scaling's lunch as the headline narrative. Between Ornith-1.5's recursive curriculum and Unsloth making local agent-quality inference viable at 6GB, the through-line is clear: the community cares less about "bigger model" and more about "model that gets better by itself, runs on my machine." CHAP signals that the human-agent collaboration plumbing layer is finally getting real protocol design attention instead of ad-hoc chat threads.
