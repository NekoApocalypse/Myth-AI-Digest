## The Stack

[Frontier Models] **GPT-5.6-Sol hits 94.4% pass@4 on corrected physics benchmarks** — An expert audit by Yale/Chicago physicists found that most "errors" attributed to frontier models on physics benchmarks were actually grader errors, incorrect reference solutions, or broken questions. After correction, frontier models are near-saturating the best physics evals we have. Time to build harder ones. <https://arxiv.org/abs/2609.13009>

[Frontier Models] **Xiaomi streams Mimo 2.6 RL post-training LIVE** — An actual dashboard showing real-time benchmark scores as RL training progresses, step by step. 2.6-Pro hit 63.7% by step 10. This is the kind of transparency US labs have been dodging for years. Say what you will about Chinese labs, but they're the ones keeping the garage door open right now. <https://mimo.xiaomi.com/rl/>

[Hardware] **Ternary LLMs break the 1.58-bit barrier with BITCOS** — By exploiting the fact that zeros dominate ternary model weights (up to 51.5%), this distribution-adaptive layout hits 1.485 bits/weight — below the theoretical 1.585-bit floor of naive ternary encoding. Real decode throughput: +18% on CPUs, +27% on GPUs across 5 platforms. Code ships with AVX-512, AVX2, and Xe2 GPU kernels. <https://arxiv.org/abs/2609.16338>

[Architecture] **Linum's JiT-DDT trains T2I models 3.6× faster at 4× resolution** — Ditches the VAE entirely for a unified pixel-space architecture with 32×32 token compression, enabled by switching from v-prediction to a more stable flow-matching objective. Apache 2.0, weights included. If this generalizes to video, it's a genuine efficiency unlock. <https://www.linum.ai/field-notes/jit-ddt>

[Agents] **Dream-RSI: recursive self-improvement via replay simulation** — Uses historical discovery trees as a replay simulator for off-policy exploration optimization in coding agents. The agent dreams on past search trajectories to improve its exploration strategy, then redeploys. Tested on algorithm engineering, math optimization, and GPU kernel engineering tasks. Substantially reduced discovery cost. <https://arxiv.org/abs/2609.14858>

[Breakout] **4B LLM beats Postgres query optimizer by 81%** — Fine-tuned from GPT-6 Astra trajectories via SFT + RL, a 4B model generates SQL query plans that achieve 44.7% latency reduction on 113 join-heavy queries. Custom GRPO variant handles the noisy RL environment of real query execution measurement. The implications for self-hosted DB optimization are real — but training cost ($800 GPU + $400 API) and non-realtime planning latency are open questions. <https://rohanbansal.com/qorl>

[Figures] **DeepMind Institute launches with essays from Hassabis, Legg, Manyika** — A new institute for interdisciplinary AGI thinking. Essays cover reasoning transparency (reading chain-of-thought to detect scheming), economic policy frameworks for AGI-era labor disruption, and a "pragmatic utopianism" framework. Not open-source code, but high-signal perspective from people who actually build these systems. <https://institute.deepmind.com/>

[Hardware] **AMD Matrix Cores get bit-accurate numerical models** — Researchers reverse-engineered the non-IEEE-754 floating-point behavior of AMD's matrix multipliers across CDNA 1/2/3 (MI100 through MI300X), producing MATLAB models validated to bit-level accuracy against 10M random tests. Includes cross-vendor comparison with NVIDIA tensor cores. Essential infrastructure for anyone building portable ML kernels. <https://arxiv.org/abs/2609.14845>
