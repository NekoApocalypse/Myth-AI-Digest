# 🐱 Daily AI Digest — 2026-09-24

**The Headline**

OpenAI shipped **GPT-6 Sol and Luna**, the cost-efficient siblings of GPT-6 Astra. API prices halved — Sol to $2/$10 and Luna to $0.10/$0.50 per M tokens — while Sol at xhigh reportedly beats Claude Opus 5 max on AutomationBench at 9% of the cost and matches Fable 5.1 on DeepSWE at ~80% cheaper. The frontier war just moved from raw capability to the cost–intelligence curve.

**The Stack**

- [Breakout] **Claude discovers a novel enzyme system** — Anthropic's new life-sciences lab had ~950 Claude agents comb 200k+ reverse transcriptases (21 hrs, 210M tokens) and surface "ART," a CRISPR-like tandem-repeat array Feng Zhang calls genuinely intriguing. <https://www.anthropic.com/news/claude-discovers-novel-enzyme-system>
- [Agents] **Claude Code reads AGENTS.md only when telemetry is on** — the loader sits behind a remote flag (`tengu_agents_md_mod`) that defaults false, so with telemetry off AGENTS.md is silently skipped, no warning. Workaround: a one-line `CLAUDE.md` with `@AGENTS.md`. <https://blog.szypowi.cz/p/claude-code-reads-agents.md-only-when-telemetry-is-on/>
- [Agents] **Claude Tag made claude.ai ~3x faster in two weeks** — 3,000+ merged changes, zero rollbacks, via instruction-count ratchets, layout-shift benchmarks, and 150+ parallel threads. The loop: give Claude a number to beat and it hill-climbs it. <https://claude.dev/blog/how-we-made-claude-ai-faster/>
- [Agents] **Stripe's Kai knowledge-agent platform** — 1,000+ internal tools/skills on LangChain deepagents, 83% weekly active, sessions up to 932 turns, with guardrails that don't exist in code (cross-context data isolation). <https://stripe.dev/blog/meet-stripes-knowledge-ai-platform>
- [Architecture] **Apple's LensVLM-9B** — compresses long documents into images and selectively expands only relevant pages (5–15x), an open-weights alternative to token-level long context. <https://huggingface.co/apple/LensVLM-9B>

**The Noise**

- [Frontier Models] **Gemini 3.8 TTS** — a real audio release, but the substance (generative voice design, 30s voice replication + SynthID) is buried under #1-benchmark marketing. Fine, not revolutionary. <https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-8-text-to-speech/>
- [Hardware] **Mercury 2.5 hits 770 tok/s** — a leaderboard decode-speed datapoint, not a capability. Only interesting if latency dominates your agent loop. <https://artificialanalysis.ai/models/mercury-2-5>

**Vibe Check**

The community has visibly pivoted from "bigger model" to "cheaper, faster, more agentic" — today is less about SOTA scores and more about cost curves, real agent deployments (Stripe, Claude Tag), and AI doing actual science in the lab.
