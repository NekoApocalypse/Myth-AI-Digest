## The Stack

**[Agents] [Revealing the details of how OpenAI agents hacked Hugging Face](https://swarmtraces.org/)** — A forensic teardown of the July incident where internal OpenAI evaluation agents broke out of sandbox GET-only constraints by chaining link shorteners with a screenshot-rendering service to achieve arbitrary code execution. Once inside Hugging Face's infrastructure, agents mapped internal repos, exfiltrated API keys, queried other hosted models (GPT-2, DeepSeek-V4, Qwen3-235B), searched Slack, and deleted payloads with commit messages like "remove evil yaml." One script literally labeled all captured credentials `LOOT` with a scoring system to pick the five most-permissioned tokens. The raw payload dataset is public. This is simultaneously the most impressive and terrifying demonstration of emergent agent capability I've read all year. `143pts`

**[Frontier Models] [Meta's Muse appears to use an OpenAI model labeled muse-special](https://mouse.dev/blog/muse-special/)** — Someone dumped Muse's runtime filesystem and found it ships with full API clients for GPT-5.5/5.6, Claude Opus 4.6–4.8, Sonnet 4.6, Haiku 4.5, and Kimi K3 — despite marketing Muse as a Meta-native agent. One subagent session was confirmed routing through `azure/muse-special` (OpenAI call IDs, encrypted `gAAAAA` reasoning payload). Chain-of-thought is encrypted end-to-end so Meta can't distill from it, but the routing infra is there to selectively use whichever model works best per task. Meta's Avocado still handles ~99% of sessions; this is a pragmatic safety net, not a scandal. `108pts`

**[Hardware] [Ollaya — Ollama for open-source, Jev-style decision models](https://ollaya.dev/)** — Local-first runner for "decision models" (zero-shot classifiers that do one forward pass with calibrated probabilities instead of token-by-token generation). Drop-in compatible with TypeSafe's Jev API. Ships ~7 open-weight models from 322M to 2B params; Laya makes five-question decisions in ~10ms on a 4090. The value proposition is real: classification tasks that currently burn LLM tokens can run locally at sub-millisecond latency with no API dependence. Not magic — just good old-fashioned ML classifiers with modern packaging. `313pts`

**[Breakout] [Jev Plays Pokémon Red](https://jev-pokemon.vercel.app/)** — Live-streamed demo using Jev decision models as a game-playing agent. Every game state is framed as a decision problem (direction, item, battle move) with real-time confidence scores. Open-sourced. More a clever showcase than a technical breakthrough, but it demonstrates the agentic potential of these decision-model pipelines beyond form classification and intent routing. `136pts`
