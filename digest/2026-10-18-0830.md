**[Architecture] You Could Have Invented Transformers From Memory** — Alex Wang (ex-Cartesia, Stanford PhD in long-context architectures) builds transformers from scratch using associative memory as the single organizing principle. Linear layers → MLPs → self-attention, each derived as a better memory store. The capacity jump is illuminating: ~64 memories (linear), ~128 (optimal least-squares store), ~2,700 (MLP with squared ReLU), to over 1,000,000 (self-attention with 64-dim keys). Interactive viz included. If you've ever wanted a clean mental model of *why* attention works, this is it. <https://alexwang.ai/posts/associative-memory/>

**[Hardware] Llmspeed** — A practical tool: pick a GPU and a model, see expected tok/s before you drop cash. Covers RTX 3090 through RTX PRO 6000, Mac Studio M5 Ultra, AMD Strix Halo, cloud H200s. Models span Qwen 3.6 through DeepSeek V4.1 Flash. Data sourced from r/LocalLLaMA and localscore.ai community benchmarks. Open source. <https://llmspeed.dev/>
