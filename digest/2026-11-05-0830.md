# AI Digest — 2026-11-05 08:30 UTC+8

## The Headline

**Anthropic ships FlashProve: zkSNARK-based provable inference at 110 tok/s for a 400B model.** You can now cryptographically prove that a model response came from the model you claim it did — weights stay hidden, verifier runs in seconds on a CPU. This isn't a paper; it ships with executable code (Apache 2.0), a Lean formal verification of the security claims, and a protocol spec. If you're building anything that touches model routing, evaluation integrity, or regulatory compliance, this is the new baseline. <https://www.anthropic.com/research/provable-inference>

[Architecture] **Ripple-65B: US open-weight SOTA on agentic coding, trained for $32M.** Ricursive (a chip-design AI lab) trained a dense 65B Transformer that beats Reflection Beam 501B on TerminalBench 2.1 (80.52 vs 80.1). The "thin-and-deep" architecture (d_model=5120, 80 layers) is optimized for local hardware like DGX Spark. The model that designs chips now ships as open-weight. <https://www.ricursive.com/ripple>

[Hardware] **Nvidia RTX Spark laptops: encrypted firmware tanks Linux GPU perf by 5x.** 65.4 tok/s on Windows → 13.9 tok/s on native Linux for GPT-OSS-120B. Root cause: the Nvidia Platform Controllers and Framework firmware encrypts its power tables, and only the Windows driver has the key. WSL is the practical workaround for now — it rides the Windows driver stack and keeps full boost. A real fix requires Nvidia to ship equivalent power management in the Linux driver. <https://www.mindstudio.ai/blog/linux-nvidia-rtx-spark-laptop>

[Architecture] **Bf16 might be silently freezing 95% of your weight updates during fine-tuning.** If you run fused AdamW directly on bf16 parameters (no fp32 master copy), updates smaller than ~|w|/512 round to zero. At lr=1e-6, only ~5% of weights can move. The author diffed the published Quiet-STaR model and confirmed exactly this pattern — only the smallest-magnitude weights changed. The kicker: rerunning with a proper fp32 master copy diverged at the same learning rate. The bf16 rounding was acting as accidental regularization. "Feature, not a bug" — but one worth knowing about before your next fine-tune. <https://lacuna.tiptreesystems.com/paper/bf16-might-be-freezing-your-weight-updates/art_487b1ed949e745a6ae0c42815b8d3cba>

[Security] **PHP2Shell: AI is forcing us to pay off 40 years of technical debt.** Calif researchers (sponsored by OpenAI) used AI tools to escalate a decades-old PHP out-of-bounds-memory bug into remote code execution — affecting NASA, Wikipedia, the White House, and every WordPress/Drupal site. The bug sat unfixed since 2024 as "just a crash." Asymmetry problem: AI makes finding exploits dramatically faster, but patching still requires making sure you don't break existing functionality. Anthropic's formal verification tools (auto-generated correctness proofs for LLM-written patches) are pointed to as the counterweight. <https://spectrum.ieee.org/ai-in-cybersecurity-php2shell-vulnerability>
