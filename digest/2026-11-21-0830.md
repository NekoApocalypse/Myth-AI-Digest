# 🐱 Daily AI Digest — 2026-11-21

## The Headline

**LLMs can now rewrite their own weights.** A 27B open model diagnosed its own failures in forward passes and edited its weights to fix them—no gradients, no training runs, just reasoning. It then repaired a broken copy of itself back to 80%+ accuracy. The wall between training and inference just got a lot thinner.

---

## The Stack

[Architecture] **Language Models Can Rewrite Their Own Weights** — Fan et al. demonstrate that a 27B model, given access to its own weights and the ability to run itself, can self-diagnose errors, edit the responsible weights, and test the fix—all through forward passes only. The capability emerges with scale (smaller models just break themselves), gains compound across 8 consecutive sessions, and the model repairs damaged copies it has never seen. This isn't test-time compute scaling—the improvement is written *into* the weights permanently. Self-rewriting is a concrete step toward recursive self-improvement. `<https://arxiv.org/abs/2611.21885>` (324 pts, 106 comments)

[Frontier Models] **Inkling 2 Mini** — Thinking Machines Lab drops a 26.4B MoE model (3.4B active) with a looped transformer architecture: middle layers run 3× per token, trading throughput for deeper reasoning. ~20GB footprint runs on a MacBook Pro. Leads all open sub-100B models on agentic coding (DeepSWE 48.2%, SWE-bench Pro v2 Hard 77.9%) and agentic search. The research variant shows no-CoT reasoning horizon extends from 16s to 37s with more loops while chain-of-thought stays legible. Open weights. `<https://thinkingmachines.ai/news/inkling-2-mini/>` (589 pts, 96 comments)

[Hardware] **Frostbite: AI-Discovered CPU Architecture** — Architect Labs used AI agent swarms to design a general-purppose CPU from ISA through RTL to final GDS, built around interaction nets instead of traditional von Neumann. 4.59× perf/W over modern superscalar cores across 25 workloads. The AI discovered novel hardware primitives that human architects would have been unlikely to conceive. Uses a formal specification language (ASL) with machine-checkable translations to Lean for verification. `<https://architectlabs.com/blog/frostbite>` (615 pts, 320 comments)

[Hardware] **Vibecoding an FPHA Inference Chip** — A developer pointed cloud coding agents at FPHA design with minimal guidance and got a working LLM inference accelerator hitting 213 tokens/s—a 33× speedup from baseline. ~3M lines of C++/Verilog, hundreds of experiments, ~$10K in API tokens. The human's most impactful prompts were "you're a superintelligent model, time to be more creative" and "let's go for 2× faster." `<https://ankitg.me/blog/vibecoding-inference-chip/>` (104 pts, 37 comments)

[Breakout] **AI Proves the Generalized Riemann Hypothesis** — Levent Alpöge used Anthropic models to generate 17.4 million lines of Lean code proving GRH. Scott Aaronson's commentary notes Lean's verification issues remain a concern but points out zero AI results with Lean certificates have needed retraction (unlike several without). Context: AI had already proved Riemann zeta zeros are ≤3/8 from the critical line. P=?NP is now the final boss. `<https://scottaaronson.blog/?p=10344>` (195 pts, 161 comments)

[Frontier Models] **Detato: 60× More Efficient Audio-to-MIDI** — A 20M-parameter model beats MuScriptor 1.3B (~65× larger) and closed-source Mirelo at audio-to-MIDI transcription, using a pitch-lane architecture that reframes transcription as a local rather than global problem. Trained on zero copyrighted recordings—synthetic + CC-only. Open source, commercial use OK. `<https://kobi.music/research/dettato>` (228 pts, 48 comments)

[Agents] **OpenComputer: Open-Source Devin Alternative** — Apache 2.0 coding agent that lives in Slack, uses Claude Code/Codex/OpenCode backend with isolated Podman containers. Opens PRs 3.3× faster than Devin in benchmarks. Self-hostable on a single VM. `<https://github.com/diggerhq/opencomputer>` (51 pts, 15 comments)

## The Noise

**OpenComputer** is trending at 51 points but it's fundamentally a thin orchestrration layer around existing coding agents (Claude Code, Codex). The Slack integration and self-hosting story are nice quality-of-life features, but there's no novel agent architecture here. If you already have Claude Code in your terminal, this doesn't change what's possible—it just changes where you type.
