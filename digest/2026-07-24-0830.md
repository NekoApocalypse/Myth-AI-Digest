## The Stack

[Agents] **Why Software Factories Fail — Dex from HumanLayer** argues that no amount of harness engineering, loopsmaxxing, or "adversarial review" prompting can fix what is fundamentally a model-training problem. The post cites Faros AI data showing PR review quality plummeting, incidents and bugs-per-dev spiking since teams adopted AI coding tools en masse. The core thesis: "lights-off" factories where nobody reads the code inevitably hit a wall when agents produce slop faster than testing can catch it. <https://github.com/humanlayer/advanced-context-engineering-for-coding-agents/blob/main/wsff.md>

[Frontier Models] **Echo — open-weight model ensemble matches Fable at 1/3 cost.** Rather than picking one model, Echo dynamically allocates compute across a pool of open-weight models (GLM-5.2, Kimi K2.7, etc.), routing each sub-task to whichever model is strongest for it. Aggregate results match Fable-level performance at roughly one-third the inference cost. The interesting bit is how *complementary* the models are — weaker models still pull weight on specific problem types. <https://echo.tracerml.ai/>

[Agents] **Screenpipe (YC S26) — turn everything you do into agent context.** Records screen + audio locally, indexes via accessibility tree + OCR, exposes a searchable timeline API for agents. The pitch: instead of manually feeding context to coding agents, they query what you've actually done. Built in Rust, local-first, with speaker diarization. This is the Karpathy-wiki / GBrain pattern taken to its logical endpoint: the agent doesn't need you to tell it what happened — it watches. <https://screenpipe.com>

[Agents] **OneCLI — credential gateway so agents never touch your keys.** OSS Rust gateway that sits between agents and APIs, storing AES-256-GCM encrypted secrets and transparently injecting them into outbound requests. Agents authenticate with access tokens; real credentials are swapped in at request time. Solves the "every agent has root" problem without requiring per-agent secret management. <https://github.com/onecli/onecli>

[Frontier Models] **Startup founders lobby against US ban on Chinese open-weight AI.** A Politico report (paywalled) on founders pushing back against proposed restrictions. The HN discussion surfaced the actual strategic dynamic: Chinese open-weight releases are "commoditize your complements" — Alibaba doesn't sell AI, it sells cloud; giving away models drives cloud demand. The encryption export control parallel from the 90s is instructive: suppression backfired then, it'll backfire now. <https://www.politico.com/news/2026/07/22/startup-founders-urge-trump-not-to-shut-off-chinese-open-weight-ai-01008992>

[Frontier Models] **The Arguments Against Open Source AI Are Very Bad —** a sharp rebuttal to the Dean Ball / Scott Galloway "AI dumping" narrative, drawing the crypto-wars parallel explicitly. Key point: open source software underpins all proprietary software, and AI models won't be different. The "AI race" framing doesn't survive scrutiny — it's not a moon shot, it's an infrastructure transition. <https://tombedor.dev/arguments-against-open-source-ai-are-very-bad/>
