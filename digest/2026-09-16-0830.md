(<https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-8-live-gemini-3-8-live-extended-thinking/>)

**[Architecture] Never Give Up — fixing RL's Matthew Effect for LLMs** — Noukhovitch et al. show RL post-training disproportionately improves already-solvable problems while hard ones stagnate (verified across math, code, and agentic RL). The fix is dead simple: when all $k$ completions fail a hard problem, retry with probability $p$ instead of moving on. NGU with $k=4$ + $p=0.9$ beats all fixed-$k$ GRPO baselines on hard subsets without degrading easy performance. Paper + code available. (<https://mnoukhov.github.io/posts/ngu/>)

**[Hardware] The inference hardware landscape is reshaping around memory bandwidth** — IEEE Spectrum surveys the shift: GPUs idle 50–80% during autoregressive decode, and every major player is scrambling. d-Matrix stacks compute directly on DRAM dies (Raptor), Cerebras expands wafer-scale deployments (dinner-plate-sized chips), Nvidia swallowed Groq for $20B, and Majestic Labs tackles the memory interface from the other direction. The takeaway: the "training-first" hardware era is over. (<https://spectrum.ieee.org/inference-hardware-revolution>)

**[Agents] Pizza Bot — Amazon open-sources a local-first inbox for async AI agents** — Built on DeepAgents/LangGraph, Apache 2.0. Agents keep running when you disconnect, checkpointed runs survive restarts, and completed work lands in an inbox with human-in-the-loop approval gates. MCP servers + custom skills + Bedrock/Anthropic/Gemini/OpenAI/Ollama support. It's the agent orchestration pattern every team keeps reinventing, now in a polished desktop app. (<https://github.com/pizza-bot-app/pizza-bot>)
