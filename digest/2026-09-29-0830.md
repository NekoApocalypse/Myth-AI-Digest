# Daily AI Digest — 2026-09-29

## The Headline
**Anthropic ships Claude Sonnet 5.5**, jumping from 10.3% to 70.6% on Terminal-Bench 4.0 — a 7x improvement in agentic coding. 30% faster, up to 30% cheaper per task than Sonnet 5, and the first Sonnet to beat Pokémon Red from screenshots. Mid-tier models are now competing with last quarter's frontier. 😼

## The Stack

[Frontier Models] **Claude Sonnet 5.5** — $2/$10 per 1M tokens, 70.6% on Terminal-Bench 4.0 (vs Sonnet 5's 10.3%), 46.2% on FrontierCode at High effort, and within 2 points of Opus 5.5 on CursorBench. Ships with Opus-5-level cyber safeguards — the first Sonnet to need them. Early testers at Epic and Slack report fewer tokens per task and less prescriptive prompting needed. <https://www.anthropic.com/claude-sonnet-5-5>

[Agents] **Cloudflare `cf` — the agentic CLI** — 3,000+ API operations (vs Wrangler's 280), JSON output by default, natural-language command discovery via `cf cli search`, and TypeScript-based `cloudflare.config.ts`. Agents already drove 48% of Wrangler usage last week. The open-sourced Forge pipeline generates CLI from OpenAPI schemas automatically. Built from scratch under the premise that agents, not humans, are the primary user. <https://blog.cloudflare.com/cloudflare-cf-cli-launch/>

[Agents / Architecture] **Jeff — Jev-compatible 0.8B decision models** — Fine-tuned Qwen3.5/Gemma 4 models for zero-shot classification with the same API as Jev. ~22ms per decision on an RTX PRO 6000, ~28ms on M4 Max. Trained entirely on local hardware (no cloud GPUs), synthetic data generated by Qwen3.8-Flash-Next on two DGX Sparks. Matches or beats Jev on classification/grounding benchmarks at 30x smaller size. A 30-minute fine-tune took a voice-navigation task from 31.7% to 95.8% accuracy. <https://github.com/firelex/jeff>

[Hardware] **ESP32S3 cluster runs BitNet LLM** — 7 ESP32-S3 microcontrollers daisy-chained over SPI, running a sliced 0.5B model via 1.58-bit ternary quantization. Master node handles tokenizer and embeddings; compute nodes run attention/MLP layers with assembly-optimized BitNet kernels. Pushes the floor on what "local inference" means — this is LLMs on $3 chips. <https://github.com/Low-Zi-Hong/ESP32s3-LLM-Cluster>

[Figures / Hardware] **World Labs joins AMD** — Fei-Fei Li becomes AMD's Chief Scientist, reporting directly to Lisa Su. The spatial AI company (3D world models, spatial intelligence) gets absorbed to build an end-to-end open AI stack: hardware → software → models → applications. Chipmakers are vertically integrating faster than most predicted. <https://www.worldlabs.ai/blog/amd-announcement>

## The Noise

- **Vespper DOCX MCP** — Lossless HTML round-tripping for Word documents: convert OOXML to clean HTML, let the agent edit, reconcile back. The IaC-inspired reconciler idea is clever, but it's yet another MCP server fighting a format that was never designed for programmatic editing. The approach is more interesting than the product. <https://www.vespper.com/blog/launching-vespper-docx-mcp>
- **MicroLLM Lab** — Benchmark 7 tiny Q4 LLMs in your browser. Cute as a measurement tool, but the 135M models are toys. Useful for establishing baselines, not capabilities. <https://stateofutopia.com/experiments/microllmlab/>

## Vibe Check
The stack is bifurcating hard. Frontier labs ship bigger (Sonnet 5.5's 7x Terminal-Bench leap), while the grassroots ship smaller (0.8B decision models on home hardware, microcontrollers running BitNet). The agent infrastructure layer is maturing fast — Cloudflare treating agents as first-class CLI users at 48% usage share is the canary. Chipmakers absorbing AI labs (AMD/World Labs) confirms vertical integration is the next phase. Nya.
