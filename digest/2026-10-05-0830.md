## The Stack

[Hardware] **<https://github.com/Niko1221/Strata>** — Strata runs Qwen 3.8 Flash Next (125B MoE) on RTX 4090/5070 or AMD RX 9070 XT at 60-100+ tok/s. Guess-and-check speculative decoding gives a 1.6-1.8x speedup. 12GB VRAM minimum, 32GB RAM recommended. The "download and double-click" UX is genuinely good — Claude Code and Cursor integration, MCP server, OpenAI-compatible API. This isn't a toy; it's a preview of what happens when frontier models meet competent consumer packaging.

[Hardware] **Homa: The end of TCP for AI clusters** — John Ousterhout (Stanford, Tcl/Tk guy) proposes replacing TCP with Homa, a message-based transport protocol designed for AI cluster networking. Receiver-driven congestion control + SRPT scheduling + switch priority queues drops P99 tail latency for short messages by ~13x versus TCP. The killer insight: inference and agentic workloads aren't bulk transfers — they're barrages of tiny KV cache queries and sync messages getting head-of-line blocked behind gradient transfers. Linux kernel module, GitHub, working on upstreaming.

[Agents] **<https://liao.gg/blog/agents-dont-need-memory>** — Kevin Liao calls bullshit on the RAG-based agent memory ecosystem. Every "memory plugin" does the same thing: chunk chat transcripts, embed them, inject top-5 similar snippets into prompts. The problems are fatal — similarity ≠ correctness, snippets lose context, stale code gets treated as truth, and you can't audit a vector store. His alternative: a structured folder of Markdown docs the agent reads before and updates after each task. Ships as Operator Memory (BSD-3-Clause, production use for 1+ years). The pitch is: AGENTS.md isn't enough; commit your agent's brain to the repo.

[Agents] **<https://github.com/allenv0/SCM>** — SCM is a polished local-first macOS app for semantic search over photos and video frames. CLIP/SigLIP for vision search, Whisper for dialogue transcription, Tesseract for OCR, optional local LLM chat over extracted text. Scene-level video search with timecode jumps. Everything on-device, no accounts, no uploads. The engineering is thorough — rename-proof content hashing, model switching with background re-embedding, per-component match scoring. A showcase for what local AI utilities should look like.
