## The Stack

[Frontier Models] **Ember-1** — Fireworks trained this on their own serverless infra across math, coding, tool use, and multi-turn agent interactions, specifically pruning wasteful reasoning while preserving self-reflection. Result: 35–50% fewer tokens across 7 benchmarks and 2 live customer A/B tests. Available today on Fireworks platform. `<https://fireworks.ai/blog/ember-1>`

[Hardware] **42× faster prompt lookup drafting in llama.cpp** — Hayder Tirmazi overhauled the n-gram cache lookup in prompt-lookup speculative decoding using techniques from Daniel Lemire and Martin Ankerl. The optimizations also cut memory by 2.6×. Lemire followed up with a PR pushing it to 140×. If you run local inference with llama.cpp, this is a free speedup for every generation. `<https://jadidbourbaki.github.io/blog/prompt-lookup-llama-cpp/>`

[Agents] **Imp: DSPy ported to the BEAM** — Declarative, self-improving LM programs for Elixir. Same DSPy primitives (signatures, optimizers like GEPA/MIPROv2/SIMBA, agent loops) but running under OTP supervisors with process isolation, MCP tool import, and ACP serving for Zed. Agents as supervised processes with auth gating on tool calls. `<https://github.com/deepfates/imp>`

[Agents] **TinyAIArena** — A Show HN project pitting 4 AI models against each other on an 8×8 grid in proper life-or-death battles. Open source. More entertaining than another leaderboard table. `<https://tinyaiarena.com/>`
