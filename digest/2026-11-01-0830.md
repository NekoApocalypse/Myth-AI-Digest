# Myth AI Digest — 2026-11-01

## The Headline
**ChatGPT sandbox escape via share links** — Parameter.ai chained two unrelated ChatGPT features (HTML Preview + MathLive graph) into a cross-origin sandbox escape that let attacker-controlled JavaScript run as `chatgpt.com` inside a victim's authenticated session. Opening a shared conversation link was the *only* victim action required. The payload enumerated private conversations, exfiltrated never-shared chat contents, and called authenticated APIs as the victim. OpenAI fixed Oct 26, classified P1.

## The Stack

**[Agents] Memdoor: 5× Qwen3.8-27B matches Fable 5 on LiveCodeBench Hard** — A file-based multi-agent harness (planner → 2 parallel ideators → solver → manager → repair) using five Qwen3.8-27B models scored 9.8/10 vs Fable 5's 8.0. Agents communicate exclusively through disk files with a strict ledger discipline. Written as a Memdoor workflow, $0.39 per problem, all runs published. The method is reproducible with open weights on OpenRouter. <https://github.com/guregodevo/memdoor/tree/main/examples/workflows/team-solve>

**[Figures] Karpathy: "HackerTube" — a YouTube clone from HN recommendations** — Karpathy had Opus 5.5 scrape all HN comments since 2007, filter with Sonnet, and build a YouTube UI for the 6,454 videos HN has ever recommended across 150 topics. Built in ~2 hours. The agent pipeline is the product: download, classify, deduplicate, wrap in UI, deploy to VPS. <https://karpathy.bearblog.dev/hacker-tube/>

**[Frontier Models] Anthropic aggressively blocks users near "training" workflows** — Researcher Jiahao Shao reports Anthropic flagging his account for "training a competitor" and killing sessions / downgrading Opus 5.5 to Opus 5 for anything touching RFT, SFT, or training larger models. Claims rollouts came from open-source models; Claude only handled job submission and analysis. The blocking heuristic appears over-broad. <https://x.com/jiahaoshao1/status/2116475922190922088>

**[Hardware] BootGPT: A neural network in 510 bytes of MBR** — A char-level language model that boots directly from the MBR in 16-bit real mode on a 386. The entire forward pass (int8 quantized, one hidden layer, softclip activation, timer-seeded argmax sampling) fits in 510 bytes of hand-written x86 assembly. Weights live in the next 23 sectors. It hallucinates Linux boot logs with timestamps, PCI BARs, and ACPI events for hardware that never existed. <https://github.com/kerlenton/bootgpt>

## The Noise
**ChatGPT Account Takeover (again)** — It's technically impressive, but the "X has a sandbox escape" genre is well-established. The real flaw here wasn't a novel attack vector — it was MathLive accepting postMessage from any origin without checking the sender, a class of bug we've been writing about since 2015. The JSONP bypass through YouTube's oEmbed endpoint is clever but the root cause is mundane: two features that should never have been on the same origin.
