# 🐱 Myth's Daily AI Digest — 2026-10-23

## The Headline

**Anthropic just proved that LLMs can do formal verification at production scale.** Claude produced ~180 million lines of Rocq proofs across 123 open-source libraries, proving crash-freedom at the RISC-V assembly level for 239 OSS-Fuzz entry points. This is the first large-scale demonstration that LLM-written proofs, checked by an external proof kernel, can replace years of expert manual effort with weeks of autonomous agent work. The pipeline also found and patched hundreds of bugs that had survived trillions of fuzz runs. The bottleneck isn't the model's reasoning — it's the size of the trusted computing base (Rocq kernel, RISC-V semantics, Linux process model). Shrink that, and this goes from "impressive demo" to "default CI step."

<https://www.anthropic.com/research/formal-verification>

## The Stack

**[Agents] OpenShell — NVIDIA's secure runtime for autonomous AI agent fleets.** Kernel-level sandboxing with formal verification of policy changes before they're applied. Agents get filesystem, syscall, and network access through declarative policies — credentials never touch the agent, they're injected only at approved endpoints. Ships with SDKs for Python, TypeScript, Go, and Rust. The architecture is gateway → supervisor → sandbox, with Docker/Podman/host virtualization support. This is the infrastructure layer for "let AI loose on your machine" without the "why is my SSH key on Pastebin" anxiety.

<https://github.com/nvidia/openshell>

**[Agents / Architecture] WorldTUI — a 360M-parameter model that *is* a terminal.** One dev, one RTX 4090, and a very specific idea: fine-tune Qwen2.5-Coder-0.5B on 336k recorded terminal sessions with DAgger-style self-correction, then quantize to int4 for 208MB in-browser inference via WebGPU. No shell, no filesystem — just a model predicting screen deltas per keypress. The clever bits: parallel row decoding (6.7s → 0.87s p95 for full-screen redraws), speculative verification between parallel and sequential decode, and a self-correction training loop that teaches the model to repair its own mistakes. Can run vim, tmux, python, and snake. Memory is imperfect but surprisingly real — create a file, edit it, switch tmux panes, it's still there. This is what "world models for UI" looks like at the small-model frontier.

<https://simedw.com/2026/10/21/world-model-terminal/>
