## The Headline

**TurboQuant in Rust, shipped.** Google Research's TurboQuant paper had the math. Now someone actually shipped it: `turbovec` compresses 10M vectors from 31GB (f32) to 4GB, searches faster than FAISS by 3.4× at 4-bit, and the SIMD kernels are hand-written for both ARM NEON and x86 AVX-512. No training phase, no parameter tuning, pure local. This is what "privacy-first RAG" looks like when you stop outsourcing your vector store.

## The Stack

**[Architecture] `turbovec` — Rust vector index on Google's TurboQuant**
A Rust + Python vector index that matches or beats FAISS PQ on recall while using ~8× less memory. Includes incremental saves (crash-safe at any byte), per-query filtering inside the SIMD kernel, and drop-in replacements for LangChain/LlamaIndex/Haystack vector stores. If you're running RAG on-prem or air-gapped, this is a genuine upgrade path from FAISS with no migration tax. 193 ★ on HN, repo at <https://github.com/RyanCodrai/turbovec>.

**[Breakout] FlyWire Connectome on Your Desktop**
A macOS app runs a real 668-neuron circuit with ~19,000 biological synaptic connections from the FlyWire connectome (Nature 2024) as a 1kHz spiking simulation. The fly decides to flee your cursor through the same Giant Fiber escape neurons a real fly uses — ~4ms reaction, same as the animal. The escape isn't scripted; your cursor position feeds the real LC4/LPLC2 looming-detector cells, and feedforward inhibition means slow approaches get ignored. Open source, MIT. <https://github.com/DenisSergeevitch/desktop-fly>

**[Frontier Models] GLM-5.3 Hits Artificial Analysis Benchmarks**
Zhipu AI's GLM-5.3 (max variant) is now on Artificial Analysis's v4.1.1 index, running against 9 evaluations including agentic coding, scientific reasoning, and hallucination benchmarks. Awaiting comparative scores against the current leaderboard — the page is live but the ranking data is still sparse. Direct technical output from one of China's top labs. <https://artificialanalysis.ai/models/glm-5-3>

**[Agents] Claude Code Ships a Real Printer Driver**
In one ~4-hour session, Claude Code reverse-engineered HP's proprietary SPL3 raster language, ran HP's real codec inside a Linux container, and produced a native macOS printer driver for the HP Laser 1008a — a printer HP never supported on Mac. This isn't a toy demo; it's a working driver produced by an agent that had to understand an undocumented raster protocol. <https://cdn.kuber.studio/chat/hp-laser-1008a-driver>

**[Hardware] DRAM Prices Up 500% in 12 Months**
128GB DDR5 kits now cost $3,399 — driven primarily by AI hardware buildout consuming fabrication capacity. The implications for anyone running local models: that 512GB inference rig just got a lot more expensive.
