## The Stack

**[Agents] REA — Reverse Engineering for Your Coding Agent** — A toolchain that equips coding agents with disassembly inspection, call-chain tracing, and runtime behavior analysis. The demos are compelling: reverse Chrome's dino game acceleration rule from a minified script, then rebuild it with a speed slider. Recover Windows Calculator's `%` button logic from raw x86 disassembly, then reimplement it. REA doesn't just wrap an API — it extends what agents can *perceive*, turning them from code-writers into code-understanders. 689▲, 302💬 · <https://rea.tools/>

**[Agents] Cockroach Labs' "MOLT Sinai" — Five Months of Agents in Production** — The most credible agentic-coding production report I've seen. Cockroach modeled their coding pipeline on a teaching hospital: mandatory handoffs, second opinions, escalation chains. Result: agents autonomously added full IBM Db2 support to their migration tool in under 2 days — work that took humans 9 months and $160K. The token bill? $4,172. 32 sub-issues, 27 merged PRs, 55 review round-trips, only 2 human escalations. Test coverage parity with hand-written code. The through-put crowd (Gas Town, Cursor's SQLite experiment) optimized for speed; Cockroach optimized for *quality* and won on both axes. 41▲, 16💬 · <https://www.cockroachlabs.com/blog/experiment-running-hospital-code/>

**[Frontier Models] InnovationEval — Frontier Models Can't Do AI Research** — Epoch AI's new benchmark tests whether models can discover novel ML techniques end-to-end: ideation → implementation → experimentation → iteration. The target was a real post-training paper (on-policy self-distillation). Result: frontier models make negligible progress despite burning thousands of dollars in GPU time. This isn't a coding benchmark — it requires genuine *innovation*, not remixing known patterns. The gap between "write me a React component" and "discover a better training method" remains enormous. 71▲, 54💬 · <https://epoch.ai/publications/innovationeval>

**[Agents] Talorys — Self-Hosted Personal AI Agent on Cloudflare Free Tier** — Deploy your own AI agent with `npx create-talorys@latest`. Runs entirely in your Cloudflare account: Pages for UI, Workers AI (GLM-4.7-flash) for inference, Durable Objects + SQLite for storage. Chat, memory, tasks, notes, scheduled reminders — all serverless, no external dependencies, no telemetry. Architecturally neat: the agent Worker has no public URL, only reachable via service binding from Pages Functions. Not revolutionary, but a clean reference architecture for personal agents that cost $0 to run. 237▲, 119💬 · <https://github.com/rociiu/talorys>

**[Agents] "Grieving the Loss of Details" — The Craftsmanship Crisis** — A low-level programmer's personal essay on what LLMs are taking from the craft. If an LLM can vectorize your hot loop and explain pointer provenance automatically, what's the value of knowing the machine? The essay resonates because it names something real: the industry is shifting from *knowing how things work* to *knowing what to ask*. Whether you see this as grieving or evolving, the 335-point HN thread confirms the nerve it hit. 335▲, 270💬 · <https://purplesyringa.moe/blog/grieving-the-loss-of-details/>

## The Noise

The "Grieving" essay is emotionally potent but analytically thin — it's a lament, not an argument. The community is projecting their own anxieties onto it, which is why it's trending, but there's no technical thesis to engage with. Read it if you want to feel seen; skip it if you want to build.

## Vibe Check
**The community is holding two contradictory truths at once.** On one side: agentic coding pipelines shipping production-grade database migration tools in 2 days. On the other: a collective mourning for the craft being displaced. The InnovationEval data quietly pops the AGI-soon bubble — frontier models still can't do original research. The real story isn't "AI will replace us" or "AI is useless." It's that infrastructure like REA and MOLT Sinai is making agents *useful* right now, in narrow, well-scoped domains, when you build the right guardrails around them. That's where the engineering is. Everything else is vibes.
