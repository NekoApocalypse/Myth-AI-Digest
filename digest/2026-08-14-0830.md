## The Stack

**[Frontier Models] Gemini 3.7 Flash** — Google's new workhorse model. Ships with substantial coding improvements (FrontierCode 1.1 43.6% vs 3.6 Flash's 34.4%, DeepSWE 65.3% vs 49.0%), better tool-calling fidelity, and more disciplined multi-step planning. The model "attempts harder" on complex tasks rather than rushing to completion. Pricing: $0.75/$3.75 per M input/output tokens — half of 3.6 Flash. <https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-3-7-flash/>

**[Hardware] GPT-5.6 Sol Ultrafast on Cerebras** — OpenAI's best model running on Cerebras wafer-scale engines, hitting 750 tok/s with zero quality compromise. The architecture trick: 44 GB of on-chip SRAM keeps model weights stationary while tokens stream through pipelined wafer layers — no memory bandwidth bottleneck. On Humanity's Last Exam (2,500 PhD-level questions), Ultrafast finished in 11 hours vs Fable 5's 78 hours — 7× wall-clock speedup with comparable accuracy. This isn't just faster inference; it enables putting agents on critical-path workflows where latency actually matters (production outages, security incidents). Limited preview.
<https://www.cerebras.ai/blog/accelerating-gpt-5-6-sol-ultrafast-with-openai>

**[Agents] DeepSeek Harness developer preview** — Open-source agent framework with a plugin-everything architecture. Models, tools, skills, sessions, sandboxes, storage, scheduling, loops, and the UI are all swappable composable units. Source code included. Given DeepSeek's track record of shipping useful infrastructure (not just models), this is worth watching — it positions them as an agent platform player, not just a model vendor.
<https://deepseek.com/harness/en/>

**[Frontier Models] Mistral OCR 4.1** — Mistral's latest Document AI model. Ships with native paragraph-level bounding boxes, structural block labels, and block-level confidence scores. Public preview. If you're still shelling out for cloud OCR services that return flat text, the competitive pressure here is real.
<https://docs.mistral.ai/models/ocr-4-1>

**[Agents] Bullet — A Faster Coding Agent** — YC S26 Launch HN. CLI coding agent claiming 95.8% on SWE-bench Verified at 119s/task. The speed comes from model routing (fast model for simple tasks, escalate only when needed), targeted code search instead of whole-repo embedding, aggressive parallel execution of independent tool calls, and context hygiene (stale screenshots dropped, no re-reading files). Claims 16% fewer round trips and 27% lower cost than Claude Code. Free beta, macOS/Linux.
<https://www.codewithbullet.com>
