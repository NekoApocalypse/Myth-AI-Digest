## The Headline

**Karpathy made Opus 5 render Middle-earth from one paragraph.** He fed Opus 5 the first paragraph of *The Lord of the Rings*, gave it a 1M token budget (~$10), and let it run unsupervised for ~2 hours. Result: 5500 lines of procedural Three.js code that animates the story — janky but functional. The implications are deeper than the demo: LLMs have unlimited stamina for tasks no human would ever budget time for. The flip side Karpathy flags is that the model can't natively perceive its own output (video/gameplay), so it had to painstakingly screenshot its own render to audit — a raw capability gap he thinks is "still quite lacking."

## The Stack

**[Hardware] BitNet: A Language Model on the 1975 6502 Processor** — A Mamba-based autoregressive LM with ternary BitNet weights, running inference on a BBC Micro (32KB RAM). 9KB code + 13KB weights = 52k parameters at 1.58 bits each. Recurrent architecture (Mamba) chosen over attention specifically because a transformer KV cache would blow the memory budget. Fully runnable in-browser via emulator with a single click. Shows how far you can push quantization when hardware constraints are absolute. <https://mattbeton.com/blog/bitnet-6502.html>

**[Hardware] NixOS on DGX Spark — Reproducible AI Hardware** — Full NixOS module and USB images for NVIDIA DGX Spark (and Asus Ascent GX10). Brings Nix reproducibility to AI hardware with 14+ playbooks covering vLLM, ComfyUI, speculative decoding, TRT-LLM, NCCL multi-node, FP4 quantization, and multi-agent chatbots. Leverages Flox pre-built CUDA packages for aarch64 to avoid compiling from source. If you're treating your DGX Spark as a dev appliance instead of a reproducible target, this is the fix. <https://github.com/graham33/nixos-dgx-spark>

**[Agents] Mu — 67 Real Tools for Agents Behind One MCP Endpoint** — Self-hosted Go binary. Not API wrappers — it runs its own SMTP server with DKIM, search index, RSS aggregator, app sandbox, and wallet. Connect once over MCP and your agent gets web search, mail, news, markets, weather, storage, calendar, contacts. AGPL-3.0, works with Claude Desktop and Cursor out of the box. The architecture pattern is the real story: register a service once and it auto-derives into MCP, CLI, web app, and internal agent surfaces. <https://github.com/micro/mu>

**[Agents] Developers Trust AI Less the More They Use It** — Stack Overflow's survey: AI usage rose 76% → 84%, but trust fell 40% → 29%. The core argument is that agentic coding made code nearly free, which shifted the bottleneck from *writing* code to *validating* it. Code review is the new crisis — agents dump hundreds of lines and humans can't keep up. LLM-as-judge is emerging as the coping mechanism. Worth reading as a snapshot of where org psychology meets agentic reality. <https://stackoverflow.blog/2026/07/29/developers-are-attached-to-tools-because-tools-encode-trust/>
