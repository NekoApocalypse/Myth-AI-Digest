# Daily AI Digest — 2026-11-13

## The Headline

**Google ships Gemini 4 Hydrogen, and Orchestrator is the real story.** Hydrogen is a competent mid-tier model (51 on AA Intelligence Index, 57% Terminal-Bench vs Flash's 18%), but the headline feature is *Orchestrator*: a dynamic routing system that switches between Carbon (frontier reasoning) and Hydrogen (fast execution) *within a single session*, not just at the start. On Terminal-Bench 4.1, Orchestrator hits near-Carbon success rates while consuming 24% less quota and finishing 19% faster. This isn't a model release — it's a statement that the multi-model orchestration layer is now table stakes.

<https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-hydrogen/>

## The Stack

[Frontier Models] **Edge0-145B: 145B parameters running locally on a laptop** — Open-source on-device model hitting 80+ tok/s at 29GB peak memory, competitive with frontier cloud models on coding and reasoning. The full stack (weights, inference framework, app) is open-sourced. This breaks the "on-device = small model" tradeoff — agentic workflows without cloud fees or data-sharing are now a hardware question, not a model-availability one. <https://edge0.ai/blog/introducing-edge0-145b-frontier-ai-capabilities-on-your-own-computer>

[Hardware] **Weight forensics reveal Chinese labs training on export-controlled Blackwell GPUs** — Unemployment Labs published forensic analysis of published model weights showing that DeepSeek, Moonshot AI, MiniMax, and Ant Group have all switched from Hopper to Blackwell hardware since April 2026. The method recovers traces of weight initialization patterns and matches them to specific GPU configurations (B200/B300 = 148 SMs, GB200/GB300 = 152 SMs) with 49–1,385 sigma confidence. Confirmed on physical Blackwell chips for DeepSeek-V4-Flash and Kimi K3. Nvidia's own Nemotron-3 Ultra, which disclosed GB200 usage, reads identically to Kimi K3's fingerprint. <https://unemploymentlabs.com/checkpoint-forensics>

[Hardware] **smolmaxxing: 16B models on a TV box** — Open-source project demonstrating practical extreme-edge inference: 16B MoE models running at 5.1 tok/s on a Xiaomi TV box with ~1GB usable RAM using custom 1-bit kernels, vocabulary pruning, and expert paging from flash. Same techniques push a jailbroken 2013 iPad Air to 24–26 tok/s for everyday models. All patches target llama.cpp. The lesson: the hardware most people already own can run surprisingly capable models if you're willing to get low-level. <https://github.com/hyperionaidev/smolmaxxing/>

[Agents] **AgentRun: agents that learn from their own runs** — Open-source platform wrapping existing agent harnesses (Claude Code, Codex, OpenCode, pi) with self-improvement, durable execution, and a control plane. Key insight: after each run, the agent persists what it learned (notes, skills, workflows) so the next run doesn't rediscover the same API or re-read the same docs. Real case study: code review costs dropped from $1 to $0.18 per review by tuning a cheap model on past agent behavior, catching 1.6x the bugs Greptile did. <https://github.com/Parcha-ai/agentrun/blob/main/README.md>

[Agents] **Apple Foundation Models framework: model-swapping as a native Swift API** — Apple ships a unified Swift API for on-device, Private Cloud Compute, and third-party models (Claude, Gemini) with Dynamic Profiles — declarative APIs for swapping models, tools, and instructions within a single continuous session. Free PCC access for small developers (under 2M downloads). The interesting bit: Apple is betting that the right abstraction for AI apps is runtime model/tool switching, not static single-model sessions. Same bet as Google's Orchestrator, different ecosystem. <https://developer.apple.com/foundation-models-framework/>

[Hardware] **Libreagi: BitTorrent tracker for OSS model preservation** — Private tracker for seeding and distributing open-source model weights (safetensors, GGUF, ONNX) with a signed public catalog so anyone can rebuild the swarm if the site goes down. Seeding incentivized by scarcity — rare models earn 4x credit. Every file verified against source commits. Infrastructure play, but the right kind: models are becoming too big and too important to trust to a single Hugging Face org staying alive forever. <https://libreagi.com/>
