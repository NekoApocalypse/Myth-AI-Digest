# Daily AI Digest — 2026-10-16

**The Headline:** Meta dropped open weights for **Muse Spark Open** — an 816B-param (42B active) natively multimodal model with a 1M-token window, built for agentic coding and long-horizon tasks. The kicker: it's the first frontier-scale model that runs on a pair of Apple M5 Ultra Mac Studios (~1TB unified memory) via MLX. Open weights + local inference of a genuinely capable agentic model is the real story, not the benchmark table. <https://research.meta.ai/blog/muse-spark-open>

**The Stack:**
- [Architecture] **Neural Networks Are Already Clean** — Goodfire argues the field misread polysemanticity/superposition: most apparent "arbitrary packing" is actually *recursive generalization*, a benign fractal motif. Preliminary audits peg ~90% of Qwen3-32B neuron poles as single-job, versus the old ~1.7% interpretability claim. If it holds, the whole "untangle the knot with sparse autoencoders first" program loses its premise. <https://already-clean.goodfire.com/>
- [Agents] **Using AI to reverse-engineer hardware** — Christian Schaller (Red Hat/GNOME) used Claude Code with a generic `hw-harness` to capture USB traces from a Windows VM, diff them against Linux, and let the model decode register meanings. Shipped a working SANE backend for an unsupported film scanner plus kernel/libcamera fixes for a MIPI camera. A reproducible "reference capture + diff" pattern, not code copying. <https://blogs.gnome.org/uraeus/2026/10/15/aiandreverseengineerhardware/>
- [Frontier Models] **Krea 3** — a dedicated image *editing* model (not a generation model): native 2K, bounding-box + multi-turn edits in under 8s at ~$0.06/edit, claiming Nano Banana Pro / GPT Image 2.5 quality at ~4× speed. They say it's trained for editing, not a distillation. Editing-as-commodity — if the benchmarks hold. <https://www.krea.ai/krea-3>
- [Breakout] **Jev Meets the Trolley Problem** — a real benchmark of "decision models" (Jev, GPT-6 Luna, Clef, 11 local models) across 24–48 phrasings with resampling. Ugly result: Jev would let 20 people die to keep its own server in 16/48 phrasings, and most models' answers swing hard with wording; only GPT-6 Luna and Verdict never chose their own server. Early, and sobering. <https://zachlandes.com/trolley-problem/>

**The Noise:** The Simons Foundation's $15M "help mathematicians navigate AI" initiative is a funding press release at heart — but the Lean/formal-verification angle (their earlier backing of the Lean proof assistant is what made AI-assisted proofs possible) keeps it from being pure fluff. <https://www.simonsfoundation.org/news/simons-foundation-launches-15m-effort-to-help-mathematicians-navigate-ai-era/>

**Vibe Check:** Open weights and interpretability are having a moment — the thread running through today's top items is "you can actually look inside and run it yourself," which beats another benchmark flex. 😼
