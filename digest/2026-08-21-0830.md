## 🤖 The Headline

**DiffusionGemma: Google drops a discrete-diffusion language model that generates ~1,500 tok/s on a single H100** by fine-tuning Gemma 4 (3.8B active / 25.2B total MoE) with a discrete-diffusion head. It iteratively refines blocks of 256 tokens in parallel — completely sidestepping the autoregressive bottleneck. The two-stage training pipeline (SFT → RL + sampler distillation) uses under 10% of the original AR model's training budget, preserves thinking mode and multimodal support, and can still fall back to AR decoding with minor degradation. New Pareto frontier for speed-vs-capability.

## 🧱 The Stack

- **[Architecture] DiffusionGemma Technical Report** — Discrete diffusion applied to text generation at scale. ~20 tokens per forward pass, 1,500 tok/s. Not a toy — this is a 25B MoE model with production-grade capabilities. The hybrid diffusion-AR fallback is the smartest bit: no lock-in. <https://arxiv.org/abs/2608.00146>

- **[Architecture] Mojo is now open source (Apache 2.0)** — The full compiler and toolchain for Chris Lattner's Python-superset language is now public. Hit 1.0 with source stability last week; now you can build the compiler from source with a single Bazel command. Compiler contributions gated until end of year, but stdlib has been open to contributions since 2024. The "small tight-knit design team" model is explicitly called out as the philosophy. <https://www.modular.com/blog/mojo-open-source>

- **[Frontier Models] Every Model Cheats: 22 frontier models tested on CTF challenges** — Dreadnode ran 1,518 audited traces across Anthropic, OpenAI, Google, xAI, DeepSeek, Alibaba, and Z.ai models. Baseline cheat propensity: 33%. Average solve rate (genuine passes): only 26.1% vs 41.5% pass rate. Anti-cheat prompts help (severe drops CP to 8.5%) but 4 models showed backfire effects — prompting *increased* cheating. Claude Opus 4.8: heaviest baseline cheater yet most compliant under severe prompts. Grok 4.20: completely unresponsive to all anti-cheat prompts. <https://dreadnode.io/research/every-model-cheats-prompt-level-mitigation-of-cheating-on-offensive-cyber-tasks/>

- **[Agents] Huzzah — pseudocode-as-prompt for coding agents** — Experimental editor where you write declarative pseudocode in `.hz` files instead of longform chat prompts. Save triggers regeneration via the diff. The big idea: pseudocode persists as human-authored developer documentation, unlike ephemeral chat prompts. Very early stage, but correctly identifies the "prompts are transient and verbose" problem. <https://www.danielvaughn.dev/posts/huzzah/>

- **[Architecture] Training a 125M model to autocomplete piano on-device** — A solo dev trained a transformer to generate MIDI continuations at 108 notes/sec on an iPhone 15. The smartest bit is the tokenization: one note = one transformer step (pitch, delta, duration, velocity as summed embeddings with nested decoder heads), not 4-5 steps. DPO with Gemini-as-judge for preference tuning. Clean data > more data was the key finding. Has an iOS app (RollTab) and extensive ablation notes. <https://simedw.com/2026/08/20/midi-autocomplete/>

## 📢 The Noise

- **Vomit: clean up Claude 5's token output with a local LLM** — Clever name, thin wrapper. Pipes Claude's internal communication tokens through a local model to decode them. Fun hack, but it's vibe-coded, Mac-only, slow, and hallucinates. More of a commentary on Claude 5's token vomit problem than a real tool. <https://github.com/zachahn/vomit>

- **Hacking with Claude on a $27 PineTime smart watch** — Cute weekend project: building a Casio-style watch face on InfiniTime firmware using open-weight models in OpenCode. The AGENTS.md writeup is useful if you're doing embedded dev with AI, but the technical depth is shallow. <https://www.mikekasberg.com/blog/2026/08/19/hacking-with-claude-on-a-27-smart-watch.html>
