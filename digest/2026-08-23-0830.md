## The Stack

[Agents] **Munder Difflin — Multi-agent harness hits HN front page** (244 pts). MIT-licensed, local-first, wraps 12 CLI coding agents (Claude Code, Codex, Grok, Kimi Code, etc.) into persistent "clones" with shared memory and E2E encrypted clone-to-clone messaging. Not a demo — clones review PRs, answer questions at 3 AM, and hand off work autonomously. Teams plan adds 24/7 cloud sandbox VMs at $149/seat. <https://munderdiffl.in/>

[Agents] **Autolith — A Common Lisp programming agent that can recover from its own death** (107 pts). Live SBCL runtime the agent inspects, redefines, tests, and commits. Handles corpora larger than the context window via recursive inference on content-addressed objects. The demo: break the running agent's formatter function, watch it crash, then watch the recovery image boot, inspect the crash capsule, restore the conversation, and continue — with the committed mutation surviving its own author. Portable S-expression conversations with exact resume. <https://www.lambda-symbolics.com/autolith>

[Agents] **NanoGPT Speedrun Frontier — 153 autonomous runs benchmark 18 models** (32 pts). Fable + Claude Code tops the leaderboard at 52,726, followed by Opus (52,920) and Kimi K3 (52,930). Each model gets 24 hours to optimize nanoGPT training code. 41 open agent traces published with full tool calls and scratchpads. Notable: DeepSeek V4 Pro ranks 13th at 3,205, Grok 4.6 at 15th with the best result but only 0.6 days of runtime. <https://www.primeintellect.ai/research/nanogpt-speedrun>

[Agents] **A week of Codex vs Claude — real dev experience comparison** (115 pts). Codex writes fewer comments and simpler architecture (less over-engineering), but Claude handles edge cases and branch intent better. Codex is faster on initial implementation, slower on PR wrap-up due to excessive test reruns. Core difference: Claude tries to go above and beyond what you asked; Codex does exactly what you tell it and stops. <https://allaboutcoding.ghinda.com/a-week-of-using-codex-more-than-claude/>

[Hardware] **Why your local LLM feels dumber than it is** (158 pts). Level1Techs forum post — content behind login wall, but the signal (158 pts, 44 comments) suggests it resonated with the local inference crowd. If anyone has access, worth a read.
