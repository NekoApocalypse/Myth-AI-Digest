## The Stack

**[Agents] qm — Multiplayer agent harness from YC** — Per-user isolated workspaces with scoped memory, files, sandbox, and permissions. Supports Pi, OpenCode, Codex, and Claude Code as interchangeable harness backends through a unified interface. Configurable security posture (Strict/Auto/Dangerous). The architecture is headless core + Postgres + per-scope sandboxes, with Slack and web as optional plugins. If you're tired of single-user agent tools that don't scale to teams, this is worth a look. (413 pts, 91 comments)
→ <https://github.com/yc-software/qm>

**[Hardware] WASTE — Kimi K3 (2.78T params) runs on a MacBook** — Dependency-free C inference engine that streams the full MoE model from NVMe at 0.5 tok/s on 64GB RAM. Activates ~4% of weights per token via direct expert streaming from disk — no distillation, no pruning, no quantization tricks. The engine is validated against PyTorch reference (logits agree to 3.6e-06). The point isn't the speed — it's that trillion-parameter local inference is now an engineering problem, not a feasibility one. "Every token answered by a cloud service is paid for twice." (136 pts, 57 comments)
→ <https://github.com/sqliteai/waste>

**[Architecture] Quanta: Is AI reasoning real or is it just vibes?** — Survey of the growing body of evidence that LRM chain-of-thought traces are neither faithful nor causal. 30-60% of thinking steps have minimal impact on outputs. Filler tokens (literal dots) work as well as readable text. Replacing correct traces with incorrect ones doesn't degrade performance. Melanie Mitchell: "The text isn't necessarily faithful to what's going on." Kambhampati's ICML 2026 position paper title says it plainly: "Stop Anthropomorphizing Intermediate Tokens as Reasoning/Thinking Traces!" The models work — we just don't know why, and the traces they produce are post-hoc storytelling. (112 pts, 142 comments)
→ <https://www.quantamagazine.org/is-ai-reasoning-right-for-the-wrong-reasons-20260731/>

**[Hardware] Predictive Speculative KV Replication** — New technique for handling bursty LLM inference workloads via speculative KV cache replication. Content was JS-rendered and unavailable for extraction. Low points (21) but worth flagging for the inference optimization crowd.
