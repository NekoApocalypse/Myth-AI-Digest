## The Stack

**[Architecture] Kimi K3 Architecture Overview** — Sebastian Raschka's breakdown of the 2.8T-parameter MoE from Moonshot AI, scaling Kimi Linear's hybrid attention design to frontier scale. The architecture converges with DeepSeek V4 and Nemotron 3 on efficiency-first choices: LatentMoE, multi-head latent attention, and attention residuals that improve validation loss at ~4% training overhead. <https://sebastianraschka.com/blog/2026/kimi-k3-architecture-notes.html>

**[Architecture] Kimi Linear: An Expressive, Efficient Attention Architecture** — Moonshot's foundational paper behind K3. Kimi Delta Attention (KDA) extends Gated DeltaNet with finer-grained gating; a 3B-activated / 48B-total hybrid model outperforms full MLA across short-context, long-context, and RL scaling while cutting KV cache by 75% and hitting 6× decoding throughput at 1M context. Open-source kernels and checkpoints included. <https://arxiv.org/abs/2510.26692>

**[Agents] OpenAI Codex Security** — CLI + TypeScript SDK for automated vulnerability scanning, validation, and remediation with CI integration. OpenAI's first dedicated security agent product — scan repos, track findings over time, run checks in CI. Requires Node 22+ and Python 3.10+. <https://github.com/openai/codex-security>

**[Breakout] Discovering Cryptographic Weaknesses with Claude** — Anthropic's Claude Mythos Preview autonomously discovered improved attacks on HAWK (NIST post-quantum candidate, halved effective key strength) and reduced-round AES (200-800× speedup over prior best). ~$100K API cost per result. Neither attack threatens production systems, but it's the first demonstration that frontier models can find mathematical flaws in algorithms themselves, not just implementation bugs. Also released CryptanalysisBench for reproducible evaluation. <https://www.anthropic.com/research/discovering-cryptographic-weaknesses>

**[Agents] MCP 2026-07-28: Transport Goes Stateless** — The Model Context Protocol drops its bidirectional session model entirely. Every request is now self-describing HTTP — no handshake, no session ID, route on headers. Multi Round-Trip Requests (MRTR) replace server-initiated calls for elicitation/sampling. List responses are cacheable. Roots, Sampling, and Logging deprecated with a 12-month offramp. Half a billion SDK downloads/month. <https://blog.modelcontextprotocol.io/posts/2026-07-28/>

**[Hardware] Running Kimi K3 on a Single M1 Max** — Deltafin runs the full 2.8T K3 MoE locally on Apple Silicon: fused NEON kernels, Metal/MPS compute, expert streaming from Hugging Face. Full install = ~1.7 TB disk, ~60-76s/token. Streaming mode = ~215 GB, minutes per token. Comes with an OpenAI-compatible API server. Practical? Barely. Impressive? Absolutely. <https://github.com/gavamedia/deltafin>
