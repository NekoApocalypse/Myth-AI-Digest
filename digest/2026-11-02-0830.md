<https://karpathy.bearblog.dev/hacker-tube/>

**[Architecture] [Proving and Improving the Platonic Representation Hypothesis with JEPAs](https://arxiv.org/abs/2610.39302)** — 105 pts
Turns the PRH from conjecture into a theorem: Joint-Embedding Predictive Architectures trained on different modalities converge to identical representations (up to a rotation) whenever positive pairs are "good views" of one scene. Next-token prediction is JEPA with "bad views," which explains LLMs' poor vision alignment. The punchline: a 109M-parameter text JEPA beats every language model up to 72B on vision alignment. Good views need 42x fewer training samples. Single rotation turns separately trained encoders into a competitive image captioner (CIDEr .838 on COCO). Code and theorem, not vibes.
<https://arxiv.org/abs/2610.39302>

**[Agents] [The AI Cost of JavaScript Frameworks](https://nolanlawson.com/2026/10/28/the-ai-cost-of-javascript-frameworks/)** — 290 pts
A rare benchmark with teeth: 12 JS frameworks/meta-frameworks, 5 agent runs each, measured on cost, time, tokens, and Lighthouse. Hono+htmx cheapest at $2.67/run median; Angular most expensive at $4.97. SPA frameworks consistently worse — more JS bytes, higher TBT. Hono+htmx and Astro produce zero blocking time and 0KiB JS. MCP/skill discoverability is a mess: Next.js agents read the skill file in only 1/5 runs. Concrete numbers for the "which framework is agent-friendly" debate, finally. Vanilla JS underperforms several frameworks — agents need some structure.
<https://nolanlawson.com/2026/10/28/the-ai-cost-of-javascript-frameworks/>

**[Figures] [Mathematics Has Changed. Let's Act Like It](https://terrytao.wordpress.com/2026/11/01/mathematics-has-changed-lets-act-like-it/)** — 207 pts
Frank Calegari (guest on Tao's blog) lays out the post-OpenAI-700-papers reality for mathematicians. Core proposals: evaluate all work as if AI-assisted, hire based on interviews not paper files, demand more from journals, prioritize problem selection and understanding over proof production. Best line: "If you, as a senior mathematician, are stressed about being scooped by AI, then you are not being ambitious enough." Not doom, not denial — a practical reorientation toward what remains uniquely human: choosing which terrain is worth exploring.
<https://terrytao.wordpress.com/2026/11/01/mathematics-has-changed-lets-act-like-it/>
