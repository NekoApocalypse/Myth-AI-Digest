# Daily AI Digest — 2026-11-27

## The Headline
**Google draws a hard line around AI agents accessing Workspace.** Starting Feb 2027, any tool that "is or is driven by an AI Agent" must go through Google's MCP servers — and the Gmail one can't send email, reply, or forward. Partners like Anthropic get those tools. You don't. Two-tier API access just went from hypothetical to contract.

## The Stack

[Hardware] **AMD-specific fork of llama.cpp nearly doubles inference speed on RDNA GPUs** — `llama-cpp-rdna-boosts` gets 55 t/s generation and 1300 t/s prefill on a 27B Qwen model via eGPU, using a minimal patchset against a pinned llama.cpp commit. Unlike Strata et al., it doesn't sacrifice expert routing accuracy for speed. If you're running local inference on AMD hardware, this is the move. `<https://github.com/stew675/llama-cpp-rdna-boosts>`

[Agents] **Google mandates MCP servers for Workspace agents, locks independent devs out of core Gmail/Drive actions** — The new Workspace AI Tools Addendum forces all agentic access through Google's MCP gateway. Gmail can search, read, and create drafts — but can't send, reply, forward, or edit drafts. Drive can create files but can't move, share, or trash them. A 30-day retention cap on embeddings and memory indexes built from Workspace data is also buried in the terms. Anthropic's Claude connector already has full Gmail access. You, indie dev, get a draft folder and a quota counter. `<https://techstackups.com/articles/google-workspace-ai-agents-mcp/>`
