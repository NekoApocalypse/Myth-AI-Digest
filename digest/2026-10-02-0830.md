## The Headline

**Context Language Models** just dropped a paper that might actually change how we think about context windows. Instead of having an external harness manage what stays in context, CLMs treat context as a file the model reads and writes natively. The model *learns* what to keep. The numbers: 11.4% higher accuracy with *21.5% fewer FLOPs* on BrowseComp-Plus, and RL fine-tuning pushes Qwen3.5-9B up 47.6% using 12% *fewer* FLOPs. Multi-agent support is baked in — each agent's context is just another file. Authors include Zettlemoyer, Lambert, Koh. This isn't a benchmark tweak — it's an architectural bet that context management belongs inside the model, not in a LangChain wrapper. <https://arxiv.org/abs/2609.37725>

## The Stack

**[Agents] Cloudflare Clef — Open-weight decision models** — Cloudflare ships Clef and Clef-flash, two models purpose-built for structured classification in agentic pipelines. Vision encoder, 64k context, Jev-API compatible, Apache 2.0. Beats Jev on most decision benchmarks with lower latency. They also launched an RL fine-tuning platform so you can train these on your own decision taxonomy. The key insight: deterministic bounded outputs for routing/classification beats using a general LLM every time. <https://blog.cloudflare.com/clef-decision-models/>

**[Architecture] RIP, vector database — turbopuffer v3** — Turbopuffer is flipping its storage engine from ANN-primary to document-primary, making vector search "just another" secondary index. Why: storage amplification (duplicating doc contents per vector), write amplification (SPFresh rebalancing cascades to all indexes), and limited vectorization (block sizes tied to cluster sizes). The rewrite fixes all three. Used in production by Cursor, Notion, and Linear — this is infrastructure that actually ships. <https://turbopuffer.com/blog/rip-vector-database>

**[Agents] Weave Router — Open-source model routing that matches Astra** — Drop-in proxy that routes every coding agent action to the optimal model in <50ms using an ONNX embedder, not vibes. Claims Astra-equivalent pass rates on Terminal Bench 4.0 and SWE Atlas at ~53% cost and 2.2-2.5x speed. Works with Claude Code, Codex, Pi, Cursor. The architecture memo mentions an HMM policy sidecar and RL-trained routing — there's actual ML under the hood, not just a switch statement. <https://github.com/weave-os/router>

**[Hardware] Janus — Go binary runs GGUF via Vulkan, no Python** — Single Go binary that runs GGUF models on AMD/Intel/NVIDIA GPUs via Vulkan. OpenAI-compatible API, hot-swap models, thinking model support, zero Python or Docker. MIT licensed. The barrier to local inference is getting comically low. <https://github.com/Vibra-Ingenn/Janus>

**[Breakout] Opus 5.5 discovers new 1615 dodo record** — A historian used Opus 5.5 + semantic search over Dutch East India Company archives to find a previously-unnoticed 1615 eyewitness report of dodo hunting, and corrected a 1890 mistranslation about the extinct red rail. The workflow: domain expertise → embedding search over archival corpus → frontier model ranks candidates → human verifies. This is what "AI-augmented research" actually looks like — not replacing the expert, but scaling their reach across millions of pages in minutes. <https://resobscura.substack.com/p/using-opus-55-to-discover-a-new-eyewitness>
