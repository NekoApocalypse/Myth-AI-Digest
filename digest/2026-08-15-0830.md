## The Stack

**[Frontier Models] GLM-5.3** — 1024 points, 508 comments, top of HN. Claims "frontier coding with emergent cyber capabilities." The z.ai blog was inaccessible at fetch time, but the HN firestorm alone makes this the most-discussed item. Watch this space: if the cyber capability claims are real (not just benchmark overfitting), this is a new threat model for AI agents. <https://z.ai/blog/glm-5.3>

**[Frontier Models] Qwen 3.8 27B** — Open-weight dense model with real agentic chops. Key numbers: CoWorkBench 70.7 (long-horizon office tasks), OSWorld-Verified 84.3 (computer use), AndroidWorld 81.9 (mobile use). The vision-language integration is native, not bolted on — it understands images, videos, and documents out of the box. FP8 weights available now on HuggingFace. <https://huggingface.co/Qwen/Qwen3.8-27B-FP8>

**[Agents] Toast 1** — Mixedbread's specialized search subagent. This is the "don't waste your frontier tokens on retrieval" thesis made concrete: matches GPT-5.6 Sol retrieval quality at 7-11x lower cost. On OfficeQA Pro V2 it SOTAs at 70% correctness ($1.15/task) vs previous best 60% ($4/task). Works with any search backend, $0.30/M input tokens. The subagent economy is real. <https://www.mixedbread.com/blog/toast-1>

**[Agents] Mole — Deep Research Agent** — Terminal-native, single static Go binary. Three things worth caring about: (1) enforced budget with ledger-level non-negative constraints — 0% overshoot, (2) every claim carries a verified verbatim quote before it reaches the answer, (3) local data stays local — the model never sees raw rows, only aggregate templates. MCP-compatible, can run in toolkit mode as a subagent. This is what "trustworthy agent" engineering looks like. <https://github.com/lajosdeme/mole>

**[Architecture] Google HEIR** — Open-source compiler that converts pre-trained AI models to run on homomorphically encrypted data. Demos: private recommendations, fraud detection, network anomaly detection, hotword detection — all with cryptographic privacy guarantees. Partnered with hardware accelerator companies (Belfort, Niobium, Cornami, Optalysys) to bring latency down. The privacy/AI tension is getting a real engineering answer. <https://blog.google/security/how-google-is-making-private-ai-practical-with-homomorphic-encryption/>

**[Breakout] Don't Classify, Hallucinate** — Ask a cheap LLM to invent plausible-but-fake categories, embed the hallucinations, dot-product against real category embeddings. Boom — correct classification without shipping a 500-label schema to the API. Implementation is a single Colab notebook. Classic "wrong tool used cleverly" pattern that saves real money at scale. The HyDE pattern graduates from RAG to classification. <https://softwaredoug.com/blog/2026/08/10/hypothetical-classifications>
