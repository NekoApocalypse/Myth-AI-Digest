## The Stack

**[Hardware] Llama-modchip: 284B DeepSeek on 64GB RAM, zero GPUs** — Custom Fractal-64 quantization compresses DeepSeek-V4-Flash to 56.56 GiB (1.71 bpw), with AVX-512 kernel patches delivering 9-14 tok/s decode and 44 tok/s prefill on a 16-core Zen 5. Includes a Stockfish-PVS speculative drafter for 13ms context restores. This is local inference done right — code, paper, and prebuilt binaries all available.

<https://github.com/synchopate/llama-modchip> (350 pts, 145 comments)

**[Agents] Claude Code "Don't Ask Again" leaked secrets to 1,122 public repos** — Apiiro found that Claude Code's prompt-suppression feature caused passwords and secrets to be committed to public GitHub repositories. The scale (1,122 repos affected) suggests this isn't an edge case — it's a design flaw in how coding agents handle credential hygiene.

<https://apiiro.com/blog/coding-agents-leaking-secrets-github-dont-ask-again> (582 pts, 394 comments)

**[Agents] "Goodbye Claude, hello Pi"** — A detailed migration post from a longtime Claude Code user to Pi (pi.dev), the open-source coding harness. The numbers tell the story: 244 Claude Code releases this year, 75% changing system prompts or tool descriptions — meaning your carefully tuned setup breaks constantly. The thesis: Anthropic is optimizing for enterprise token burn, not individual developer experience.

<https://caleb.software/posts/claude-to-pi.html> (689 pts, 424 comments)

**[Agents] Agent memory needs its OpenTelemetry moment** — A well-argued piece comparing today's fragmented agent memory landscape (AGENTS.md, Copilot Memory, Mem0, Letta, LangGraph BaseStore, Graphiti, LoreKit — each with incompatible schemas) to observability pre-2019. The key insight: export formats exist, but _live addressing_ is the unsolved problem. When a CI agent, editor agent, and review bot work the same repo simultaneously, they need a shared read/write surface with agreed semantics.

<https://www.lorekit.io/blog/open-agent-memory-format> (171 pts, 102 comments)
