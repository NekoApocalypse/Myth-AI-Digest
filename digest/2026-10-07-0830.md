## The Stack

[Frontier Models] **Mistral Large 4** — 1T/49B MoE, open weights coming. SOTA on cybersecurity (93% Cybench), beats GPT-6 Astra on visual grounding, scores 61.7% DeepSWE. Trained entirely in European datacenters. The RL post-training pipeline produces 33B tokens/day across 3K GPUs and the run is still in flight with no saturation. <https://mistral.ai/news/mistral-large-4/>

[Frontier Models] **OpenAI releases AI-generated math results** — 722 manuscripts from an internal frontier model, with Lean formalizations, reasoning traces, and compute cost estimates (avg ~3 hours of ChatGPT Pro thinking per result). Plans to open-source the model itself. Advisory guidance from IAS's AGMAI group. <https://openai.com/index/sharing-ai-progress-in-mathematics/>

[Agents] **OpenAI Decisions API (public beta)** — Dedicated classification endpoint on `gpt-6-luna`. Predicates (probability), choices (selection), and scores (rubric evaluation) at ~10x the speed of Responses API. Text + image input. This is the API you use when you need a model to route, classify, or gate — not generate. Unlocks fast agent decision loops without full inference overhead. <https://developers.openai.com/api/docs/guides/decisions>

[Architecture] **EmbeddingGemma 2** — 740M-param multimodal embedder (text + image + audio + video) from Google DeepMind. Apache 2.0. Matryoshka embeddings (768→128 dims, 6x storage reduction). Runs on-device at ~191MB quantized for text, 8K context. 9.9-point MTEB Code improvement over v1. This is the embedder you pair with local RAG. <https://blog.google/innovation-and-ai/technology/developers-tools/embeddinggemma-2/>

[Hardware] **OpenTPU — AI-designed AI accelerator** — Full open-source chip: SystemVerilog RTL, ISA, simulator, compiler, kernel language, all in one monorepo. Runs 10 real models (Qwen3, LFM2.5, Gemma 4, Phi-4-mini…) on a $200-ish Kintex-7 FPGA card at usable speeds. The chip was designed by AI; the chip then runs that same class of models. 52 tok/s on LFM2.5-230M. If you've ever wanted to understand an AI accelerator from matmul to wires, this is the repo. <https://github.com/fesens/OpenTPU>
