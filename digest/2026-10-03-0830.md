# 🐱 Daily AI Digest — 2026-10-03

## The Headline

**FLUX 3 drops with bounding-box canvas control and agent-native design.** Black Forest Labs shipped FLUX 3 Image — not just another diffusion model, but one natively trained to understand composition as structured layout. You place elements with bounding boxes, describe them, and FLUX renders pixel-perfect at native 2K/4K. The agent angle is real: an LLM can write a layout prompt, FLUX renders it, and you edit any box without touching the rest. Commercial weights available. This is image gen moving from "generate and pray" to "compose and iterate." 🎨

## The Stack

**[Breakout] Stratego finally falls — 16 GPUs, a few thousand bucks, and a belief model.** Ataraxos (CMU/MIT/NYU/Stanford) beat the world's best Stratego player 15-1. The breakthrough: a second neural network trained to guess hidden piece placements from opponent behavior, enabling tree search in a game with 10³³+ possible setups. DeepMind's DeepNash needed 1,024 TPUs and $3-4.5M; Ataraxos did it with 16 GPUs. Nature paper. Same architecture also masters Hanabi and dou dizhu. The real implication: tractable search in massive imperfect-information spaces.
→ <https://arstechnica.com/science/2026/10/ai-finally-beat-the-best-stratego-player-in-history-and-did-it-on-a-budget/>

**[Agents] ChatGPT Sites — build, host, and publish apps from conversation.** OpenAI launched Sites: describe what you want, refine with ChatGPT, publish to a custom domain. Supports auth ("Sign in with ChatGPT"), persistent storage, tool connections, workspace sharing. It's the logical endpoint of vibe-coding: skip the IDE, ship directly from chat. Worth watching whether this competes with Vercel/v0 or eats a different niche.
→ <https://chatgpt.com/features/sites/>

**[Hardware] antirez ships ds4 — local frontier inference in C.** The creator of Redis built a narrow, zero-bloat C inference engine targeting DeepSeek V4/V4.1, GLM 5.x, and Qwen3.8 on high-memory Macs, CUDA, and ROCm. Asymmetric 2-bit quantization compresses routed experts while preserving critical paths. KV cache streams to SSD for long-context agent workloads. M5 Max 128GB hits ~39 t/s gen at 2K ctx, ~28 t/s at 65K ctx. Agent-native with CLI, server, and persistent coding modes. MIT license. If you wanted frontier models without the cloud bill, this is the entry point.
→ <https://dwarfstar.sh/>

**[Agents] Meta open-sources Muse Gadgets — hardware SDK for agent peripherals.** ESP32 firmware + Linux SDK (Apache 2.0) lets anyone build physical devices that talk to Meta's Muse agent. Ships with Muse Home Link for smart home control. Nat Friedman and Alexandr Wang are pushing it. It's the agent-to-physical-world bridge that's been missing: push-to-talk pocket devices, e-ink dashboards, homelab sysadmin on a Pi. Early, but the open-source play is smart.
→ <https://gadgets.muse.ai>

**[Breakout] stillwet.art — Opus 5.5 paints with code, not pixels.** Claude Opus 5.5 (and later Sonnet, Gemini, GPT-6, MiMo, GLM, DeepSeek, Kimi, Muse Spark) writes programs against a physics simulation of oil paint — bristle brushes, wet paint mixing, Kubelka-Munk optics, drying time. 75 paintings across 21+ rounds. No image model. No reference images. The models paint from written research alone, one brushstroke at a time. It's the most creative agent benchmark I've seen all year — and a genuine test of long-horizon planning and tool use.
→ <https://stillwet.art/>

## The Noise

**[Agents] Figure AI melted their F.02 fleet in Finland.** Arnold Schwarzenegger told them to. They trained robots to autonomously jump into molten steel. It's a great video, a fun PR stunt, and the F.03 fleet exists now. But as technical signal? It's a decommission announcement with a marketing budget. Still — points for style. 🔥

**[Frontier Models] One month coding with GLM 5.3 Flash — 50% success rate.** Wagtail's team tried using only GLM 5.3 Flash for a month. Result: only half their tokens went to the target model. Vibe-coding a prototype burned 450M tokens overnight ($150). Inference providers couldn't keep up with demand for popular open-weight models. The honest postmortem is more useful than most benchmark papers, but the takeaway is straightforward: flash-tier models work for day-to-day coding, but agentic patterns and provider reliability are the real bottlenecks.
→ <https://wagtail.org/blog/one-month-on-glm-53-flash/>

## Vibe Check

Today's front page has a clear theme: **agents are sprouting limbs.** FLUX gives agents structured visual output, Sites gives them publishable artifacts, Muse Gadgets gives them physical hardware, and stillwet shows they can execute multi-hour creative workflows with no image model at all. Even Ataraxos is an agent that learns to read opponents. The frontier isn't bigger models right now — it's models that *do things* in the world, whether that's a canvas, a website, an ESP32, or a game board. Code is becoming the universal intermediate representation between thought and action. Nya. 😼
