## The Stack

**[Frontier Models] GPT‑6.1 Sol** — Matches GPT‑6 Astra on DeepSWE v1.1 at ~1/5 the cost; doubles GPT‑6 Sol's score on Terminal-Bench Science at max reasoning effort while costing 75% less than Astra or Opus 5.5. Cached input at $0.10/M tokens. Factuality error rate reduced ~32% over GPT‑6 Sol. The pricing model ($2/$10 per M input/output) makes high-reasoning agent loops financially viable for the first time in OpenAI's ecosystem. <https://openai.com/index/introducing-gpt-6-1-sol/>

**[Agents] Dots — Always-on agents** — OpenAI's first production agent platform: persistent agents with their own cloud computer and browser, learning from feedback, working 24/7 across ChatGPT, Slack, and Teams. Key detail: proactive research runs read-only in background when you're not actively working with it. Specialist dots for enterprise (procurement, support, contracting) in pilot. The architecture implication: this is OpenAI committing to the "agent as persistent compute" paradigm, not just chat-with-tools. <https://openai.com/index/introducing-dots/>

**[Architecture] Jeeves — Reasoning improves Jev-like decision models** — PostHog open-sourced a 9B classifier (Qwen3.5-9B + LoRA + pointer head) trained with SFT and CISPO (RL from MiniMax-M1) that thinks before deciding. Beats Jev across-the-board: 0.889 vs 0.857 on held-out test data, 0.935 vs 0.866 on JevBench. Block-4 diffusion drafter yields 1.6× speedup. Full training code, weights, and Jev-compatible API included. The RL recipe (CISPO with early stopping at step 402 to preserve calibration) is worth studying. <https://github.com/PostHog/jeeves>

**[Frontier Models] Livenerf — Is Opus 5.5 getting nerfed?** — A pre-registered, statistically rigorous benchmark tracking Anthropic's Claude Opus 5.5 for post-launch degradation. Runs a calibrated panel of 78 questions daily for 30 days with hermetic execution (frozen prompts, pinned CLI, exact-match grading). Built on UK AISI's Inspect framework with Anthropic's own error-bar methodology. Detects ~7.5-point accuracy shift per 10-day window. Currently 6/30 days into baseline collection. Code available. <https://github.com/ninjahawk/livenerf>

**[Agents] Corral — Kill every command your agent starts** — Linux tool guaranteeing zero leftover processes after an agent or CI command returns. Uses cgroup v2 (kernel-enforced) or child subreaper mode to catch daemons that double-fork, processes ignoring SIGTERM, and background jobs holding stdout open. Exit code 120 = unverified cleanup. Tiny, focused, solves a real problem for anyone running AI coding agents in production. <https://github.com/Cardinal44/corral>
